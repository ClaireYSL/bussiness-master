# L5 候选来源与入池路径说明 v1

## 摘要

本文件用于明确回答两个问题：

1. 当前静态潜客池中的 `L5` 主要从哪里来
2. 一个新公司进入 `L5` 时，标准入池路径是什么

本说明只服务当前 `静态潜客池`，不包含：

- 动态机会判断
- 联系人线索
- 第三方招聘平台信号
- 销售推进状态

## 一、L5 的主要来源

当前 `L5` 主要来自 4 条路径，不是随机搜公司名后直接入池。

### 1. 从已有高质量样本向外扩

这是最核心的来源。

做法是：

1. 先从 `L1-L3`、现有重点公司、已知客户案例中提取稳定画像
2. 再找与这些样本在业务形态、经营复杂度、商业模式上相邻的公司
3. 经过最小证据与边界判断后进入 `L5`

这类 `L5` 的特点是：

- 不是凭感觉加进去
- 而是“从已验证样本向外扩出来”的候选

### 2. 从历史候选池与旧批次清洗收敛

当前静态池里一部分 `L5` 来自历史沉淀，而不是本轮现搜。

典型来源包括：

- 旧版外部目标客户池批次
- 首版真实内容批次
- 历史扩展候选池
- 早期放量名单

这些历史候选不会原样继承，而是需要经过：

1. canonical 去重
2. alias 对照
3. 老客排除
4. 边界主体过滤
5. 最小证据补齐

之后才允许进入当前 `L5`。

### 3. 从公开静态信息源判断

当需要新增 `L5` 时，主要依赖公开静态信息，而不是动态信号。

优先使用的来源包括：

- 官网
- 年报 / 财报 / 招股书
- 官方新闻 / IR 页面
- 高可信公开资料
- 行业资料与已有样本映射

这条路径主要回答：

- 这家公司做什么
- 商业模式是什么
- 客群和经营复杂度是否成立
- 是否符合某个主线和业务形态画像

### 4. 从画像与知识资产反推补池

有些 `L5` 不是先看见公司，再决定是否入池，而是：

1. 先已有较清楚的画像
2. 再按画像去补一批合理候选

例如：

- 多门店连锁零售画像清楚后，去补更多零售网络型主体
- 多平台品牌出海画像清楚后，去补更多品牌出海主体
- 多工厂制造集团画像清楚后，去补更多集团型制造主体

这条路径本质上是：

- 先有画像
- 再找公司

## 二、当前不作为 L5 主要来源的内容

以下信息当前不作为 `L5` 的主要来源：

- 联系人线索
- 销售推进反馈
- 第三方招聘平台信号
- 动态商机判断
- 时间敏感项目窗口

原因是这些信息主要回答的是：

- 现在要不要优先动作

而 `L5` 当前回答的是：

- 这家公司是否值得先进入静态潜客池

## 三、L5 标准入池路径

一个新公司进入 `L5` 时，应按以下顺序执行：

### 用户直接提供名单时的额外规则

如果输入不是“单个公司”而是“用户给的一批客户名单”，那么这批名单的角色是：

- `候选来源`
- 不是 `可直接入池结果`

因此在标准入池路径前，必须先多做一步：

#### Step 0：名单校验与分流

1. 先查：
   - `alias_registry`
   - `legacy_customer_registry`
   - 静态池事实主表
2. 先排除：
   - 已在池里的主体
   - 相近重复主体
   - 已知存量客户 / 签约主体
3. 再判断哪些公司：
   - 能稳定回到某条主线
   - 能稳定回到某个业务形态画像
   - 属于静态潜客，而不是动态机会线索

处理结果默认分成三类：

1. `可进入 L5 的候选`
2. `待补信息后再判断`
3. `不适合进入静态池`

只有第一类，才继续走下面的标准入池路径。

### Step 1：先定主体

先做：

- alias 检查
- canonical account 检查
- 老客排除

只有主体锚点明确后，后续信息才允许回挂。

### Step 2：先看官方源

优先找：

- 官网
- 年报 / 财报 / 招股书
- IR 页面
- 官方新闻

优先确认：

- 产品与服务
- 商业模式
- 客群
- 公开存在的系统/数字化建设事实

### Step 3：再补高可信公开源

再看：

- 交易所公告
- 权威媒体
- 行业研究
- 政府 / 展会 / 项目公开资料

用于补强：

- 业务复杂度
- 组织背景
- 重大事件
- 全球化或区域化经营特征

### Step 4：再做画像与知识映射

在主体与静态背景已基本成立后，再做：

- 主线判断
- 业务形态画像判断
- 管理诉求画像辅助解释
- 知识资产映射

这一步是解释层，不应反过来替代事实采集。

### Step 5：满足最小标准后进 L5

最低要求包括：

- 主线
- 主画像
- 一句话入池理由
- 至少 1 条最小证据
- 来源说明
- 当前待验证项

满足后才允许进入 `L5`。

## 四、L5 与动态机会层的边界

当前 `L5` 代表的是：

- 已满足静态入池最低标准
- 但信息厚度和记录成熟度仍低于高质量层

`L5` 不代表：

- 现在就值得销售优先跟进
- 当前有明确项目窗口
- 已经存在联系人推进条件

这些判断应留给未来动态机会层。

## 五、当前执行口径

当前默认口径可以概括为：

- `L5` 主要来自样本外扩、历史清洗、静态公开信息判断、画像反推补池
- `L5` 不来自动态机会信号
- 新增时必须先定主体，再收静态信息，再做解释映射
- 用户给名单时，名单先过校验与分流，再决定哪些能正式进入 `L5`
