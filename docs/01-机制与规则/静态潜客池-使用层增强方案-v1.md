# 静态潜客池-使用层增强方案-v1

## 摘要

本方案定义静态潜客池下一阶段的 `使用层` 增强方式，目标是让同事更容易直接看懂、筛选、分享和协作，而不是只面对一张全量主表。

本轮使用层增强重点：

1. 共享版 Excel
2. 重点公司 note 模板
3. 专题包模板

## 一、共享版 Excel 增强

### 目标

在不破坏 Excel 事实源的前提下，提供更适合团队阅读和筛选的共享层视图。

### 建议展示区

#### 账户识别区

- 公司主体
- 品牌名
- 主线
- 业务形态画像
- 管理诉求画像（显示层）
- 信息扎实度
- ICP匹配概率
- 静态潜客记录成熟度

#### 公司背景区

- 公司产品与服务概述
- 商业模式概述
- 核心客户客群
- 收入规模区间
- 营收增长概述
- 已上线系统概况
- 数字化项目动态
- 近一年重大事件

#### 解释区

- 一句话入池理由
- 主要知识资产引用
- 主要切入话术引用
- 待验证项

### 不直接暴露的内部字段

- cleanup/merge 技术细节
- 过细的 evidence 明细
- review queue 内部状态

## 二、重点公司 note 模板增强

### 目标

让重点公司 note 从“解释一家公司为什么在池里”，升级成“既能解释、也能拿去讲”。

### 推荐结构

1. 公司是谁
2. 为什么在池里
3. 为什么重要
4. 业务形态画像
5. 管理诉求画像
6. 信息扎实度 / ICP匹配概率 / 静态潜客记录成熟度
7. 公司背景快照
8. 案例/方案资产
9. 切入话术资产
10. 待验证项
11. 证据摘要

### 公司背景快照块

建议固定为：

- 业务与商业模式
- 财务与增长
- 数字化与系统
- 招聘与重大事件

## 三、专题包模板增强

### 目标

让专题包不只是“名单 + 理由”，而是能直接被业务同事拿来讨论和转发的协作材料。

### 推荐结构

1. 专题范围
2. 为什么这类公司值得看
3. 对应主线
4. 业务形态画像
5. 管理诉求画像
6. 代表账户
7. 背景快照摘要
8. 对应案例/方案
9. 切入话术
10. 当前待验证重点

## 四、当前边界

本轮使用层增强仍不做：

- 动态机会排序
- 联系人视图
- CRM 输出结构
- 销售流程动作编排

## 五、验收标准

当以下条件满足时，视为使用层增强方案完整：

1. 同事能通过共享版更容易看懂账户
2. 重点公司 note 能同时回答“是什么 / 为什么 / 怎么讲”
3. 专题包可以直接从现有主表、画像、知识资产和话术资产派生
