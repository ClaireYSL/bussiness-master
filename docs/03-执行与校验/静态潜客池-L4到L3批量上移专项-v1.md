# 静态潜客池-L4到L3批量上移专项 v1

## 摘要

本专项连续完成一轮批量上移，将 `20` 家潜客从 `L4` 上移至 `L3`。

本轮上移目标不是只改层级，而是同时完成：

1. 记录成熟度上移
2. 背景快照补齐到高质量层复用标准
3. promotion evidence 写回
4. review queue 关闭
5. 共享层与浏览层同步
