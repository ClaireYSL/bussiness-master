# 静态潜客池-L3扩容专项-v1

## 摘要

本次专项直接运行 `static-pool-promote` 的批量上移逻辑，在用户已明确给出：

- 连续推进
- 允许跳过问题对象
- 目标是不间断地把总 `L3+` 做到 `150+`

的前提下，跳过选项卡阶段，直接进入批量执行。

本轮结果：

- 总 `L3+`：`83 -> 153`
- 本轮新增 `L3`：`70`
- 当前分层：`L1=8 / L2=35 / L3=110 / L4=1 / L5=204`

## 执行原则

本轮采用以下执行口径：

1. 优先保证 `L3+` 总量目标达成
2. 对明显高风险对象直接跳过，不让问题对象阻断整体上移
3. 优先选择：
   - `先进制造`
   - `跨境电商`
4. 不把动态机会逻辑混入本轮上移
5. 上移同时同步：
   - 主表
   - 潜客档案库
   - evidence
   - review_queue
   - `L3+` 客户档案页
   - `L3+` 客户档案索引

## 当前判断

本轮已经达成用户的核心目标：

- 总 `L3+` 达到 `150+`

但这不代表这 `70` 家都已经具备 `L2` 级强样本质量。

更准确地说，这批对象现在是：

- 已进入 `L3` 的可读档案层
- 已具备继续筛选、沉淀、分享的最低可用形态
- 后续仍应继续补：
  - 官方源
  - 高可信源
  - 更强字段级 evidence

## 下一步建议

下一步最合理的动作不是继续无边界冲量，而是：

1. 从这批新 `L3` 里挑一批最稳的对象继续做 `L3 -> L2` 评估
2. 继续补强：
   - 官方经营披露
   - 业务颗粒度
   - 关键背景字段
3. 再决定哪些对象值得：
   - 进入重点公司 note
   - 后续进入团队共享包
