# BusinessMaster 主线推进路线图 M12-M16 v1

## 1. 主线定位

BusinessMaster 当前阶段的主线不是继续堆单批次写回，而是把静态潜客池建设成一套可持续经营系统：

`知识库 -> 画像 -> L5 候选 -> enrich 补强 -> promote 上移 -> writeback 治理 -> share 消费`

当前已经验证的能力：

1. 事实源、工作簿、候选批次、写回闸门已能串成闭环
2. `review_status` 历史口径已完成兼容，系统性 block 已解除
3. Milestone 11 已把 `evidence_thin`、`generic_product`、`generic_admission` 降为 0
4. LLM 委派已接入，可作为画像复核、知识抽象和补证建议的增强层

当前真正瓶颈：

1. 画像边界仍未收敛，6R/11 回归样本仍有 `persona_boundary_unstable=12`
2. 知识库还没有充分转成稳定规则资产
3. 合格静态潜客池仍缺少可批量消费的稳定候选集
4. share 层还需要围绕“为什么值得看、证据够不够、下一步做什么”形成消费闭环

## 2. 核心板块成熟度

| 板块 | 当前成熟度 | 质量判断 | 下一步重点 |
| --- | --- | --- | --- |
| 知识库 | 中 | 有素材和复盘，但知识资产化不足 | 形成行业画像、证据等级、准入规则资产 |
| 画像体系 | 中低 | 已进入 promote 判断，但边界不稳 | 先做 12 家主画像稳定性复核 |

| 迁移交接 | 中 | 已有自检和 handoff 雏形 | 固化环境、LLM、路径、工作簿自检 |

## 3. Milestone 12：主画像稳定性复核与画像体系收敛

目标：把 Milestone 11 剩余的 `persona_boundary_unstable=12` 从笼统 warn 变成可解释、可复核、可治理的判断。

执行方式：

1. 用 6R/11 的 12 家作为固定回归样本
2. 生成抽象输入包，仅包含结构化字段、证据摘要和当前 promote 结论
3. 使用 LLM 产出画像稳定性复核草稿
4. 人工或规则确认后，生成画像复核结果包
5. 只对证据和画像均稳定的对象建议转 `active`
6. 继续通过 `report_only -> gate_check -> write_back -> post_integrity` 闭环验证

成功口径：

1. `persona_boundary_unstable` 明显下降
2. 仍保留 warn 的公司必须有明确业务原因
3. 不要求本轮全部 allow
4. LLM 输出不得直接写回，只能作为复核草稿或建议包输入

## 4. Milestone 13：知识库资产化与规则沉淀

目标：把反复出现的判断经验沉淀为可复用知识资产，而不是只停留在一次性复盘文档中。

建设内容：

1. 行业画像定义与边界
2. 证据强弱等级与适用场景
3. 常见 warn/block 原因解释
4. 候选准入和上移判定样例
5. 产品泛化、入池理由泛化、画像漂移的识别规则

成功口径：

1. 后续候选筛选和 promote 能引用稳定知识资产
2. 新画像或新行业接入前有知识资产入口
3. LLM 只能辅助草拟知识条目，最终仍以本地注册表和人工复核为准

## 5. Milestone 14：合格静态潜客池扩容

目标：在画像与规则稳定后，从 12 家回归样本扩展到更大候选批次。

扩容策略：

1. 先小批量扩大，不直接大规模写回
2. 按主线或画像分组推进
3. 每轮保留候选快照、run summary、gate check 和 post integrity
4. 每轮必须回答候选是否漂移、baseline 是否一致、工作簿是否健康、写回是否串行

成功口径：

1. 形成一批可消费 L5/L3/L2 候选
2. 每家公司有清晰画像、证据、入池理由和治理状态
3. 批次结果可复跑、可解释、可迁移

## 6. Milestone 15：共享消费与业务使用闭环

目标：让静态潜客池从“数据工程结果”变成业务可消费资产。

建设内容：

1. 公司摘要
2. 画像解释
3. 证据索引
4. 风险与待补证说明
5. 下一步建议动作
6. 面向销售、研究、运营或 agent 的共享视图

成功口径：

使用者能快速回答：

1. 这家公司为什么值得看
2. 它适合哪个画像
3. 当前证据够不够
4. 还有什么风险
5. 下一步该做什么

## 7. Milestone 16：迁移、交接与长期运行机制

目标：确保另一个 agent 或另一台机器能无歧义恢复项目运行。

建设内容：

1. 环境自检
2. `.env` 与 LLM delegate smoke
3. `STATIC_POOL_ROOT` 与工作簿路径检查
4. workbook integrity
5. handoff snapshot
6. 标准批次操作说明

成功口径：

项目不依赖口头记忆；按文档和脚本即可恢复执行、验证、写回和复盘。

## 8. 当前默认下一步

默认进入 Milestone 12，不继续扩大候选池，直到画像稳定性问题被解释或解阻。
