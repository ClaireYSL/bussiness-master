## 3. 三张表分别负责什么

### 3.1 `raw_material_inventory`

这是原素材全量盘点表。

它负责回答：

1. 原始 PDF / DOCX / MD 素材在哪里
2. 它属于什么来源根和文件类型
3. 当前处于什么状态
4. 是否已经进入学习队列
5. 是否已经转成正式知识资产

当前确认的关键字段包括：

- `material_id`
- `material_title`
- `material_path_or_url`
- `source_root`
- `file_type`
- `track_guess`
- `persona_guess`
- `material_status`
- `linked_asset_ids`
- `linked_queue_ids`
- `priority`
- `next_action`

它是“原素材位置账”。

### 3.2 `learning_queue`

这是知识学习队列表。

它负责回答：

1. 哪些原素材已经进入待学习状态
2. 当前抽取进行到哪一步
3. 是否已经可转正式知识资产
4. 某条素材是因什么场景进入学习流程

当前确认的关键字段包括：

- `queue_id`
- `material_title`
- `material_path_or_url`
- `material_origin`
- `material_type`
- `trigger_scene`
- `trigger_account_id`
- `trigger_track_id`
- `trigger_persona_id`
- `proposed_asset_type`
- `proposed_title`
- `source_verified`
- `extraction_status`
- `ready_for_registry`
- `priority`
- `last_touched_at`
- `owner_note`

它是“学习进展账”。

### 3.3 `knowledge_assets`

这是正式知识资产表。

它负责回答：

1. 哪些素材已经完成学习并转正
2. 当前有哪些正式可复用知识资产
3. 每条资产回指哪个原始来源

当前确认的关键字段包括：

- `asset_id`
- `asset_type`
- `title`
- `source_path_or_url`
- `source_origin`
- `track_ids`
- `persona_ids`
- `customer_refs`
- `jtbd_tags`
- `complexity_tags`
- `summary`
- `key_signals`
- `recommended_usage`
- `confidence_level`
- `last_reviewed_at`

它是“正式资产账”。
