# 03-执行与校验-归档迁移清单-v1

## 1. 文档目的

本文件用于解决 `docs/03-执行与校验/` 当前过载的问题。

本次目标不是立刻移动文件，而是先明确三件事：

1. 哪些文件应继续留在 `03-执行与校验`
2. 哪些文件应整体迁入 `archive`
3. 哪些文件暂时保留但后续待复核

当前判断依据是：

- `03-执行与校验` 共 `87` 份文件
- 其中 `客户档案修复批次-*` 就有 `54` 份

这已经说明该目录不再适合继续被视为“当前执行入口目录”，而更像“过程记录堆场”。

---

## 2. 迁移原则

后续对 `03-执行与校验` 应固定采用下面 3 条原则：

### 2.1 只保留“当前索引”和“当前仍复用的专题”

留在 `03` 目录中的文件，应满足至少一条：

1. 是当前阶段的总索引
2. 是当前阶段仍会反复引用的执行总控
3. 是跨批次、跨专题的复用型校验文档

### 2.2 单批次执行记录默认不留在现行目录

以下类型文档原则上都应迁入归档：

1. 单批次修复记录
2. 单轮试运行记录
3. 已被新版本覆盖的阶段专项
4. 已不再代表当前主线的试运行文档

### 2.3 不先删，只先分流

本轮不删除任何文件，只做清单分流。

建议未来迁移目标目录采用：

- `docs/archive/执行记录/客户档案修复批次/`
- `docs/archive/执行记录/专项过程/`
- `docs/archive/执行记录/试运行记录/`
