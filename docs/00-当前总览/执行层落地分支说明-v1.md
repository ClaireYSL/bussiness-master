# 执行层落地分支说明-v1

## 分支信息

- 分支名：`codex/execution-layer-foundation`
- 分支目标：把 `expand + enrich + promote` 三核执行层按当前设计真正落成可用执行底座

## 为什么要单开分支

这轮工作不再是局部补丁，而是要把执行层从“设计已明确、实现不完整”推进到“有通用入口、有结果包、有小样本定向回写”的状态。单开分支有两个目的：

1. 避免当前主线继续混入局部修补和历史兼容调整。
2. 把这轮工作明确收成一个独立目标：执行层底座落地。

## 本分支只做什么

本分支只覆盖三条主执行线：

1. `expand`
2. `enrich`
3. `promote`

优先级固定为：

1. `enrich` 主入口落地
2. `expand` 入口纠偏
3. `promote` 接 enrich 结果
4. `Phase 1` 的 `15` 家样本定向回写

## 本分支不做什么

本分支明确不做：

1. 不做全量潜客池回洗
2. 不做全量档案重修
3. 不做新一轮知识学习
4. 不做 cleanup / share 的通用引擎
5. 不做向量化或知识底层重构
6. 不做跨境 / 制造的完整专题扩池脚本

## 当前验收对象

本分支的主验收对象固定为 `Phase 1` 的 `15` 家样本，不扩展到全量池。

这 `15` 家样本将用于验证：

1. 是否能完成 enrich
2. 是否能重算主画像 / 次级画像
3. 是否能回挂强相关知识资产
4. 是否能进入 promote 决策
5. 是否能完成小样本定向回写

## 本分支的结果沉淀位置

默认优先沉到：

1. 结构模板
2. 共享校验层
3. 通用脚本入口
4. enrich / promote 结果包
5. `15` 家样本定向回写结果

不默认沉到：

1. 全量池真相源回洗
2. 全量档案修复
3. 新知识学习产出

## 本分支的完成标志

本分支完成时，至少要满足：

1. 已有独立 `enrich` 执行入口
2. `expand` 已完成入口纠偏，不再默认偏零售
3. `promote` 已能消费 enrich 结果
4. `15` 家样本完成 enrich + promote + 定向回写
5. 有一份分支复盘文档，可直接作为后续入口
