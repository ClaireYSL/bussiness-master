# 静态潜客池-L5到L3扩容专项-v2

## 目标

在不降低 `L3` 门槛的前提下，对当前 `L5` 中最适合做公开披露补强的对象完成一轮 `L5 -> L3` 批量上移。

## 本轮选择原则

仅处理同时满足以下条件的 `L5`：

1. 来源于 `公开主体名单批量扩展 2026-03-30`
2. `legacy_customer_check_status = passed`
3. `dedupe_status = canonical`
4. `review_status = auto_ingested`
5. 可稳定回到上市公司公开披露入口

这意味着本轮不是为了放量而放量，而是只处理那批可以被统一补到 `L3` 最低标准的对象。

## 本轮结果

- 处理对象：`110`
- 全部完成：
  - 公开主体名单 + 行业分类 + 上市公司公开披露补强
  - 档案层标准化
  - `L5 -> L3` 上移
  - `L3+` 客户档案页创建

## 当前边界

本轮仍然保持：

- `收入规模区间`
- `利润状态概述`
- `营收增长概述`

统一为 `待补公开财报口径`，不允许用市值、二手猜测或模型推断替代。

这也是本轮“不降低标准”的关键边界之一。

## 下一步

这 `110` 家虽然已经进入 `L3`，但后续若继续上移到 `L2`，仍必须继续补：

- `L5 -> L3` 允许先达到可读档案层最低可用
