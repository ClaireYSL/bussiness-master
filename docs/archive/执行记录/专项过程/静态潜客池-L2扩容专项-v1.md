# 静态潜客池-L2扩容专项-v1

## 摘要

本次专项在当前 `L3+` 已达到 `153` 的基础上，继续运行 `static-pool-promote`，目标是将至少 `50+` 个 `L3` 上移到 `L2` 或 `L1`。

本轮执行策略是：

- 不把 `L1` 冲量化
- 以更稳的方式，将一批已经具备高质量样本条件的 `L3` 批量上移到 `L2`
- 优先处理：
  - `先进制造`
  - `跨境电商`

本轮结果：

- 新增 `L2`：`55`
- 当前分层：`L1=8 / L2=90 / L3=55 / L4=1 / L5=204`
- 高质量层总量保持：`153`

## 执行原则

本轮采用以下原则：

1. 优先把已经具备高质量样本条件的 `L3` 提升到 `L2`
2. 不为了完成数量目标而强行扩大 `L1`
3. 上移同时同步：
   - 主表
   - 档案库
   - evidence
   - queue
   - `L3+` 客户档案页
   - 索引与团队共享索引

## 当前判断

这一轮完成后，静态池的高质量样本层已经从“以少量锚点 + 一批可用 `L3`”的状态，进一步收敛为：

- 一组更大的 `L2` 可复用样本层
- 仍保留少量 `L1` 作为核心锚点
- 剩余 `L3` 保留为继续观察与后续筛选层

这使得后续：

- 重点公司沉淀
- 专题包复用
- 团队分享

都具备更厚的样本基础。
