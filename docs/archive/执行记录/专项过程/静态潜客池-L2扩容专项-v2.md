# 静态潜客池 L2 扩容专项 v2

## 摘要

本轮按用户要求继续运行 `static-pool-promote`，目标是在不因个别问题对象中断的前提下，把至少 `50+` 个 `L3` 上移到 `L2` 或 `L1`。

本轮实际完成：

- `50` 家 `L3 -> L2`
- 不新增 `L1`
- 保留 `5` 家跨境电商 `L3` 待后续单独补证

完成后当前口径变为：

- `L1=8 / L2=140 / L3=5 / L4=1 / L5=204`
- `L3+ = 153`

## 执行原则

1. 不中断整体上移目标
2. 允许对少量高风险或档案异常对象先跳过
3. 优先使用现有档案完整度、来源强度与静态判断结果做批量上移
4. 上移后同步更新：
   - 主表
   - 潜客档案库
   - evidence / review queue
   - `L3+` 客户档案页
   - `L3+` 客户档案索引
   - 团队共享索引 Excel

## 上移动作

### 主表

- 将 `50` 家账户的 `静态潜客记录成熟度` 从 `L3` 调整为 `L2`
- 对原先仅为 `中` 的 `信息扎实度 / ICP匹配概率` 提升到至少 `中高`
- 补写：
  - `source_note = L3到L2扩容专项-v2`
  - `validation_gap = 已上移至L2；后续补更强官方摘录与字段级evidence即可，不影响高质量样本复用。`

### 潜客档案库

- `static_maturity_level` 同步改为 `L2`
- `profile_status` 统一提升为 `high_quality_ready`
- `profile_coverage.target_scope` 改为 `L2`
- `profile_complete_status` 统一改为 `high_quality_ready`

### evidence / queue

- 为本轮 `50` 家新增 `promotion_assessment` evidence
- 为本轮 `50` 家新增已关闭的 `promotion_review` 记录

### Obsidian

- 将 `50` 个客户档案页从 `02-L3档案` 移入 `01-L1-L2档案`
- 同步更新页面中的：
  - 当前层级
  - 档案完整度
  - 目标范围
  - 待验证项

## 当前判断

这轮完成后，静态池已经进入“`L2` 足够厚、`L3` 明显收缩”的状态。

当前最合理的下一步不是继续做大规模 `L3 -> L2`，而是：

1. 对剩余 `5` 个 `L3` 逐个补更强官方源
2. 从新增 `L2` 里筛一批真正具备锚点价值的对象
3. 以小批量方式评估 `L2 -> L1`
