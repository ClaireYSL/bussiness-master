# 静态潜客池-L3到L2批量上移专项-v3

## 目标

在不降低上移标准的前提下，对当前 `L3` 中已满足门槛的对象做一轮 `L3 -> L2` 批量上移。

## 本轮门槛

仅允许同时满足以下条件的 `L3` 上移：

1. `信息扎实度 = 中高`
2. `ICP匹配概率 ∈ {中高, 高}`
3. `profile_status = standard_ready`
4. `official_source_count >= 1`
5. `high_confidence_source_count >= 2`
6. `primary_source_types = 公开主体名单,行业分类,上市公司公开披露`

## 本轮结果

- 当前 `L3` 总量：`167`
- 满足门槛并完成上移：`118`
- 保留在 `L3`：`49`
