## 2.4 当前判断字段口径

从这一版开始，围绕静态潜客池统一使用以下三字段：

1. `信息扎实度`
2. `ICP匹配概率`
3. `静态潜客记录成熟度`
4. `静态优先级`

说明：

- `信息扎实度`：表示当前信息、证据与主体边界有多扎实
- `ICP匹配概率`：表示基于当前已知信息，对其符合目标客群画像的阶段性判断
- `静态潜客记录成熟度`：表示该记录在静态池中的综合成熟度，对应 `L1-L5`
- `静态优先级`：表示在当前成熟度层内，谁更值得优先补证、优先解释、优先进入上移评估
- `L1-L5` 不再单独承担“匹配判断”含义，也不代表动态机会强弱
