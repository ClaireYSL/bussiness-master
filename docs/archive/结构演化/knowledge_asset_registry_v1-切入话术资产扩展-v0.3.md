## 本轮作用

这批资产不解决“这家公司是不是在池里”，而是解决：

- 这家公司为什么值得这样讲
- 从什么经营问题切入更自然
- 同事在专题包、分享材料、重点公司说明里该怎么表述

因此它们的定位是：

- 重点公司解释增强
- 画像解释增强
- 专题包输出增强
- 分享材料增强

## 使用边界

切入话术资产尤其需要明确边界：

- 这类资产是对真实案例、真实项目经验和真实行业认知的整理表达
- 不是独立成立的一手知识源

因此：

- 话术资产可以帮助统一讲法
- 不能单独替代案例、证据、档案或官方材料
- 不允许使用 `internal://narrative/...` 或内部占位文档直接生成正式话术资产

后续使用时，应默认回到：

- 真实客户案例
- 潜客档案
- evidence
- 官方 / 高可信来源

来确认它为什么适用，而不是把话术本身当作事实依据。
