# 外部目标客户池 v1.0 第十一至第十二批关键账户强核验 v0.1

## 1. 文档目的

本文件继续从第十一批及相邻高价值候选中挑选最值得上移的账户做强核验。

目标：

- 继续把 `L5` 中更像“准补充标尺”的账户往上提
- 让零售消费、跨境电商、先进制造三条主线都继续增厚高质量层
- 在总池已达 `300+` 后，优先提升静态池的密度与可解释性

## 2. 本轮核验对象

本轮选择以下 6 家：

- 周黑鸭国际控股有限公司
- 元祖股份有限公司
- 梦天家居集团股份有限公司
- 开润股份有限公司
- 机器人股份有限公司
- 株洲中车时代电气股份有限公司

选择原因：

- `周黑鸭`、`元祖` 代表零售消费里更明确的连锁零售画像
- `梦天家居`、`开润股份` 代表跨境经营与品牌出海的边界高质量样本
- `机器人`、`时代电气` 代表先进制造里自动化装备与高技术电气制造样本

## 5. 当前结论

这轮说明：

1. 零售消费里连锁食品零售画像可以继续稳定上移。
2. 跨境电商里家居与消费品出海边界账户也能被压实，而不只是停留在候选层。
3. 先进制造里机器人与轨交电气画像开始形成更强补充标尺。
