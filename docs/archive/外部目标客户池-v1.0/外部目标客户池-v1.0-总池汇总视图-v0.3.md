## 4. 当前总池的结构意义

### 4.1 L1-L3：已压实的高质量层

这部分账户的作用是：

- 提供稳定的画像锚点
- 提供可复制的补充标尺
- 给后续继续扩池提供边界校准

### 4.2 L4：待进一步压实层

这部分账户方向成立，但还缺更强公开依据或画像边界收紧。

### 4.3 L5：大规模放量层

这部分账户已符合静态入池标准，且已有明确入池理由，但尚未经过强核验上移。

当前 v1.0 要做大的主要就是这一层，但不能放弃向上提纯。

## 6. 当前判断

当前节奏仍然有效：

1. `每轮新增 30-40 家` 放量候选

按这个节奏推进，总池能继续稳定接近 `300+`，且不会把质量完全稀释掉。
