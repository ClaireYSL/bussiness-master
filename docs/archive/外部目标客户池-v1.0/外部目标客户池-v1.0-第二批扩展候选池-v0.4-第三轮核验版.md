# 外部目标客户池 v1.0 第二批扩展候选池 v0.4 第三轮核验版

## 1. 文档目的

本文件继续推进第二批扩展候选的强核验，目标是进一步扩大 `高可信补充样本` 与 `中高可信补充样本`，为第三批扩池提供更厚的标尺集。

## 2. 本轮核验对象

本轮选择以下 4 家做第三轮核验：

- 比音勒芬服饰股份有限公司
- 北京石头世纪科技股份有限公司
- 浙江杭可科技股份有限公司
- 拓斯达科技股份有限公司

选择原因：

- 分别补足零售消费、品牌出海、先进制造装备、新增制造自动化方向
- 与现有高可信母样本和补充样本的画像相邻度较高

## 6. 当前结论

到这一步，第二批扩展池已经不再只是“候选池”，而是开始沉淀出一组足够可用的 `补充标尺集`：

- 零售消费：周大生、晨光文具、比音勒芬、水羊
- 跨境电商：科沃斯、致欧、石头科技、绿联
- 先进制造：中航光电、杭可科技

这组标尺集已经足以支持继续拉第三批候选。
