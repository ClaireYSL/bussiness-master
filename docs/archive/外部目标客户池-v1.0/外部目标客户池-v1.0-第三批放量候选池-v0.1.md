## 1. 文档目的

本文件基于当前已经形成的：

- 第一批高可信母样本

本批对象属于：

- `第三批放量候选层`

- 高可信母样本

- 动态机会池

## 3. 放量原则

### 3.1 优先沿现有标尺集扩展

第三批优先从以下已成立画像继续扩：

- 多门店连锁零售
- 高 SKU 品牌消费品
- 多平台多店铺品牌出海型
- 供应链复杂的跨境经营型企业
- 多工厂离散制造集团
- 研产销协同复杂的技术型制造企业

### 3.2 不追求平均分配

第三批仍然遵守：

- 零售消费优先放量
- 跨境电商次之
- 先进制造继续精选

### 3.3 不把候选层与样本层混用

第三批账户进入候选层后，仍需后续强核验，才能升级为补充样本。
