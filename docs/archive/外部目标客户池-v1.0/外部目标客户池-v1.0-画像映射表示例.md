# 外部目标客户池 v1.0 画像映射表示例

## 1. 文档目的

本文件给出 `persona_to_accounts_case_map_v1` 的填写样例，帮助后续正式建池时统一理解：

- 一类画像应该如何定义
- 应该映射哪些外部潜客
- 应该映射哪些内部样本和案例
- 应该如何给前线提供切入话题

以下示例用于说明结构和口径，不代表完整最终名单。

## 2. 样例结构

每条画像示例包含：

- 画像名称
- 画像定义
- 外部筛选特征
- 不适用边界
- 代表性外部潜客类型
- 对应存量客户
- 对应案例 / 方案 / 场景包
- 推荐切入话题
- 推荐触达方式

## 3. 示例一：多门店连锁零售

### 画像名称

多门店连锁零售

### 画像定义

总部管理半径大、门店和区域经营差异显著、需要从总部到区域到门店做经营穿透和动作闭环的连锁零售企业。

### 外部筛选特征

- 连锁零售 / 商超便利 / 连锁服务
- 多门店
- 多区域
- 总部强管理
- 门店经营复盘频繁

### 不适用边界

- 单店或少量门店的小品牌
- 主要依赖单一电商渠道、没有明显线下管理半径的公司

### 代表性外部潜客类型

- 全国或区域性连锁零售集团
- 商超便利品牌
- 连锁美业 / 服务业品牌

### 对应存量客户

- 鲜丰水果
- 来伊份
- 博士眼镜
- 7-Eleven（牛奶公司 / 惠康集团）

### 对应案例 / 方案 / 场景包

- 连锁零售经营分析平台型方案
- 总部到区域到门店穿透类案例
- 门店经营健康度 / 区域差异 / 一线动作闭环场景

### 推荐切入话题

- 总部经营透视
- 门店经营健康度
- 区域差异分析
- 一线动作闭环

### 推荐触达方式

- 电话+邮件
- 活动邀约

## 4. 示例二：高 SKU 品牌消费品

### 画像名称

高 SKU 品牌消费品

### 画像定义

SKU 多、渠道复杂、库存与动销压力大，需要围绕商品、渠道、库存、业财供协同做经营分析的品牌消费品企业。

### 外部筛选特征

- 美妆个护 / 食品饮料 / 母婴宠物 / 品牌消费品
- SKU 多
- 渠道多
- 库存压力大
- 动销与补货决策复杂

### 不适用边界

- SKU 极少、渠道极简单、主要依赖单一销售路径的品牌

### 代表性外部潜客类型

- 品牌消费品集团
- 多渠道品牌商
- 高 SKU 快消 / 美妆 / 母婴企业

### 对应存量客户

- 自然堂
- 君乐宝
- 元气森林
- 王小卤

### 对应案例 / 方案 / 场景包

- 渠道 / 商品 / 动销增长分析方案
- 业财供协同型方案
- 商品、库存、渠道、补货、费销场景

### 推荐切入话题

- 商品与库存优化
- 渠道与动销分析
- 业财供协同

### 推荐触达方式

- 电话
- 邮件
- 活动邀约

## 5. 示例三：多平台多店铺品牌出海型

### 画像名称

多平台多店铺品牌出海型

### 画像定义

在多个跨境平台和多个国家市场运营，需要在市场洞察、选品、平台经营和利润分析之间建立统一分析框架的品牌出海企业。

### 外部筛选特征

- 品牌出海
- 多平台
- 多店铺
- 多国家
- 海外业务体量较大

### 不适用边界

- 只在单平台、单区域、小规模试水的跨境卖家

### 代表性外部潜客类型

- 品牌出海企业
- 多平台精品卖家
- 海外业务占比较高的消费品牌

### 对应存量客户

- 乐其 SmallRig
- 东南亚出海标杆类案例样本

### 对应案例 / 方案 / 场景包

- 跨境电商 ABM 物料
- 市场洞察与选品
- 多平台经营分析
- 海外业务经营驾驶舱

### 推荐切入话题

- 多平台精细化运营
- T+1 利润分析
- 市场洞察与选品

### 推荐触达方式

- 邮件
- 活动邀约
- 伙伴转介绍

## 6. 示例四：多工厂离散制造集团

### 画像名称

多工厂离散制造集团

### 画像定义

拥有多个工厂、产线和事业部，需要通过经营驾驶舱和计划协同实现集团级管理透明化的制造企业。

### 外部筛选特征

- 离散制造
- 多工厂
- 多事业部
- 集团化经营
- 管理协同链条长

### 不适用边界

- 单工厂、单事业部、经营链路简单的制造企业
- 仅强调底层生产控制，而不强调经营协同的工厂型项目

### 代表性外部潜客类型

- 多工厂制造集团
- 技术型设备制造企业
- 医疗器械 / 消费电子 / CDMO 集团

### 对应存量客户

- 零跑汽车
- 颐顿机电
- 昊志机电类案例样本

### 对应案例 / 方案 / 场景包

- 制造业经营驾驶舱
- LTC / 多工厂计划协同
- 财务 / 生产 / 质量 / 存货联动

### 推荐切入话题

- 集团经营驾驶舱
- 多工厂计划协同
- LTC 与经营透明化

### 推荐触达方式

- 伙伴转介绍
- 电话前置沟通
- 定向活动邀约

## 7. 正式建池时的使用规则

1. 每个画像先用本文件结构补齐定义，再去挂公司。
2. 外部潜客映射必须先满足画像定义，不能只因行业相同就纳入。
3. 内部样本和案例优先使用已归一的品牌 / 集团映射。
4. 如果一个公司同时像多个画像，主表只保留一个主画像，其他画像作为补充说明。
