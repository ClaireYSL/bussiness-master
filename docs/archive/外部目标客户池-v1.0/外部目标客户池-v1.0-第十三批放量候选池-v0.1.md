# 外部目标客户池 v1.0 第十三批放量候选池 v0.1

## 1. 文档目的

本文件在前十二批基础上，开启新一轮增量扩池。

这一批的策略是：

- 不再沿用旧批次的“存量待迁”思路
- 直接面向新增高质量静态潜客做扩池
- 优先补充食品饮料、连锁餐饮、品牌出海家居/消费电子、装备与高端零部件制造

## 2. 筛入原则

本批账户必须满足：

1. 属于零售消费、跨境电商、先进制造三条主线之一
2. 能映射到当前 `active` 画像
3. 有一句话说清楚为什么应入池
4. 已做明显主体重复排除
5. 不与当前结构化主表中的 canonical 账户重复
