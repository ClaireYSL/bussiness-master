# 外部目标客户池 v1.0 第八批放量候选池 v0.1

## 1. 文档目的

本文件继续扩展第八批放量候选。

当前目标不变：

- 持续扩大 `高质量静态潜客总池`
- 保持画像边界不漂
- 保持每个账户都有明确入池理由

## 2. 筛入原则

本批账户必须满足：

1. 属于零售消费、跨境电商、先进制造三条主线之一
2. 能映射到当前已成立画像
3. 有清晰可表达的入池理由
4. 已做明显同名主体排除
5. 不与当前已有潜客池账户重复

## 4. 本轮扩池结果

本轮新增第八批候选 `36` 家：

- 零售消费：12 家

- 先进制造：12 家

## 5. 当前意义

第八批扩池后，总池继续覆盖到：

- 食品与调味品等高 SKU 品牌消费品
- 品牌服饰和户外零售
- 户外、宠物、材料与运动器材等出海画像
- 驱动控制、汽车零部件、工业车辆与自动化装备制造

这使三条主线的外延继续扩大，同时保持了入池逻辑的可解释性。
