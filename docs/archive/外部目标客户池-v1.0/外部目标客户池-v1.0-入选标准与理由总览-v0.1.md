# 外部目标客户池 v1.0 入选标准与理由总览 v0.1

## 1. 文档目的

本文件用于回答一个核心问题：

`一个公司为什么会进入当前静态潜客总池？`

目标不是重复已有字段定义，而是把当前建池过程中真实在用的判断标准和入选理由，整理成用户可直接理解的说明。

## 2. 先说结论

一个公司进入 v1.0 静态潜客总池，不是因为“它看起来是大公司”或“行业热门”，而是因为它同时满足以下两类判断中的大部分：

1. `客观上像观远的理想客户`
2. `观远当前有较强的案例、方案或画像支撑去覆盖它`

当前不会因为以下原因直接入池：

- 只是知名品牌
- 只是上市公司
- 只是近期热度高
- 只是看起来可能会买

## 3. 入池判断的五个核心标准

## 3.1 行业与战略主线匹配

公司必须首先落在当前三条主线中至少一条：

- 零售消费
- 跨境电商
- 先进制造

说明：

- 这只是第一层门槛
- 行业匹配本身不构成入池充分条件

### 典型入池理由

- 属于品牌零售 / 连锁零售 / 品牌消费品
- 属于品牌出海 / 多平台跨境经营
- 属于离散制造 / 技术型制造 / 多工厂制造集团

## 3.2 经营复杂度成立

公司必须具备足够强的经营复杂度，否则不值得进入平台型潜客池。

当前重点看的复杂度包括：

- 多门店 / 多区域 / 总部强管理
- 高 SKU / 多渠道 / 库存与动销复杂
- 多平台 / 多店铺 / 多国家 / 海外经营
- 多工厂 / 多事业部 / 研产销协同复杂

### 典型入池理由

- 总部到区域到门店的经营穿透需求明确
- 商品、渠道、库存之间存在高频协同压力
- 海外业务和平台经营复杂到需要统一分析框架
- 制造企业已具备集团级协同和经营透明化需求

## 3.3 JTBD 类型成立

公司进入总池，必须能被映射到明确的业务任务，而不是泛泛地“需要数字化”。

当前常见 JTBD 类型包括：

- 总部经营透视
- 门店经营健康度
- 商品与库存优化
- 渠道与动销分析
- 多平台精细化运营
- T+1 利润分析
- 海外业务经营驾驶舱
- 集团经营驾驶舱
- LTC
- 财务 / 生产 / 质量 / 存货联动

### 典型入池理由

- 该公司能自然对应到观远已有场景包
- 前线可以讲出明确切入话题

## 3.4 观远匹配度成立

即便公司很像目标客户，如果当前观远没有足够支撑，也不应轻易纳入高质量池。

当前重点看的支撑包括：

- 已有存量客户样本
- 已有案例
- 已有方案类型
- 已有场景包
- 已有 AI+BI 叙事

### 典型入池理由

- 可以明确找到对标样本客户
- 可以明确讲出类似案例或方案
- 不是“只能靠想象去卖”

## 3.5 证据强度可分层

v1.0 不要求所有公司一上来都证据同强，但要求它们能被分层。

当前采用的层级是：

- `L1` 高可信母样本
- `L2` 高可信补充样本
- `L3` 中高可信补充样本
- `L4` 中可信候选
- `L5` 放量候选

### 典型入池理由

- 就算暂时不是强样本，只要方向成立且画像清晰，也可以先进 `L4/L5`
- 但必须能说明“为什么先进池”

## 4. 三条主线的具体入池逻辑

## 4.1 零售消费

更容易入池的公司通常满足：

- 门店网络明显
- 区域经营差异明显
- 商品 / 渠道 / 库存复杂
- 总部管理半径大
- 品牌消费品属性强

### 常见入池画像

- 多门店连锁零售
- 高 SKU 品牌消费品
- 连锁餐饮 / 茶饮 / 咖啡

### 典型入池理由写法

- 多门店、多区域、总部强管理，适合总部经营透视
- 高 SKU、多渠道、库存和动销压力共存，适合商品与渠道分析
- 加盟 / 直营混合，适合门店经营透视和加盟管理

## 4.2 跨境电商

更容易入池的公司通常满足：

- 多平台
- 多国家
- 品牌出海
- 利润核算复杂
- 海外经营已经形成规模

### 常见入池画像

- 多平台多店铺品牌出海型
- 供应链复杂的跨境经营型企业

### 典型入池理由写法

- 全球品牌出海属性明确，适合海外业务经营驾驶舱
- 多平台 / 多区域经营复杂，适合多平台精细化运营分析
- 跨境履约链路长，适合 T+1 利润分析和库存协同

## 4.3 先进制造

更容易入池的公司通常满足：

- 多工厂
- 多事业部
- 全球经营或集团经营明显
- 研产销链路长
- 财务 / 生产 / 质量 / 存货联动复杂

### 常见入池画像

- 多工厂离散制造集团
- 研产销协同复杂的技术型制造企业

### 典型入池理由写法

- 多工厂、多业务协同明显，适合集团经营驾驶舱
- 技术型制造属性明确，适合 LTC 和经营透明化切入
- 全球经营和高端制造特征明显，适合作为先进制造画像候选

## 5. 不入池或暂缓入池的常见原因

以下情况即使公司有名，也不应轻易入池或不应轻易升层：

- 行业在主线内，但经营复杂度不足
- 行业在主线内，但 JTBD 只能泛泛描述
- 行业在主线内，但观远当前几乎没有样本和案例支撑
- 只有品牌热度，没有足够主体或经营资料支撑
- 更像动态机会逻辑，而不是静态匹配逻辑

## 6. 用户该如何读当前总池

如果用户要判断“这家公司为什么在池子里”，建议按以下顺序看：

1. 看它属于哪条主线
2. 看它属于哪个画像
3. 看它为什么符合该画像
4. 看观远对应的样本和案例是什么
5. 看它当前处于哪个层级
