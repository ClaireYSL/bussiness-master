# 外部目标客户池 v1.0 第十二批放量候选池 v0.1

## 1. 文档目的

本文件继续扩展第十二批放量候选。

这一批的策略是：

- 不机械追求固定批次数量
- 优先保证新增账户干净、不重复、画像边界稳定
- 继续提升静态潜客池的覆盖广度

## 2. 筛入原则

本批账户必须满足：

1. 属于零售消费、跨境电商、先进制造三条主线之一
2. 能映射到当前已成立画像
3. 有清晰可表达的入池理由
4. 已做明显同名主体排除
5. 不与当前已有潜客池账户重复

## 4. 本轮扩池结果

本轮新增第十二批候选 `23` 家：

- 零售消费：8 家

- 先进制造：11 家

## 5. 当前意义

第十二批扩池后，总池继续覆盖：

- 烘焙、乳品、卤味、珠宝、百货等零售消费细分
- 家居与材料类跨境经营主体
- 重工、船舶、机床、智能物流与高端零部件制造

这让总池在保持静态匹配逻辑的前提下继续增厚边界覆盖。
