## 3. 层级定义

本视图统一使用以下层级：

### `L1-高可信母样本`

- 已经通过较强官方或年报级依据压实
- 可作为后续扩池的标尺

### `L2-高可信补充样本`

- 已通过多轮核验
- 可作为画像扩展的补充标尺

### `L3-中高可信补充样本`

- 已有较强方向性证据
- 可作为次一级参考样本

### `L4-中可信候选`

- 方向成立
- 但证据仍不足以升到补充样本层

### `L5-放量候选`

- 沿标尺集扩出的第三批候选
- 尚未进入强核验阶段
