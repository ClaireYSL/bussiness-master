# 外部目标客户池 v1.0 第九批放量候选池 v0.1

## 1. 文档目的

本文件继续扩展第九批放量候选，目标是把静态潜客总池继续稳定推向 `300+`。

本批仍坚持：

- 不因为追总量而破坏画像边界
- 不把动态机会判断混入静态入池逻辑
- 每个新增账户都能讲清楚入池理由

## 2. 筛入原则

本批账户必须满足：

1. 属于零售消费、跨境电商、先进制造三条主线之一
2. 能映射到当前已成立画像
3. 有清晰可表达的入池理由
4. 已做明显同名主体排除
5. 不与当前已有潜客池账户重复

## 5. 当前意义

第九批扩池后，总池进一步覆盖：

- 食品、烘焙、饮品与便利商超
- 纺织服饰、家居与新材料出口经营主体
- 工程机械、自动化装备、汽车电子与能源装备制造

这让三条主线继续向更大规模的静态潜客池推进，同时仍保持可解释性。
