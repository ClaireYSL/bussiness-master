# 外部目标客户池 v1.0 第二批扩展候选池 v0.1

## 1. 文档目的

本文件基于当前已经压实的 `高可信母样本` 做同画像扩展，用于把池子从第一批种子账户继续外延到第二批候选账户。

这批对象的定位不是：

- 高可信母样本
- 已核验优先池

而是：

- `按母样本扩展的候选账户`
- `方向成立，但仍需进一步核验`

## 2. 使用方式

本批候选账户适用于：

- 后续扩池
- 画像边界验证
- 活动邀约池扩展
- 二次核验优先队列

不适用于：

- 直接当作高可信母样本
- 直接替代第一批压实账户

## 3. 来源说明

本批候选账户采用以下逻辑筛入：

1. 与当前高可信母样本处于相同或相近画像
2. 经营复杂度、业务模式、集团化程度与现有画像兼容
3. 已与合作名单做过 `明显同名主体排除`
4. 当前仍需补进一步官方 / 年报 / 经营复杂度核验

## 5. 当前建议

第二批扩展账户的正确用法是：

1. 先挂到对应画像下
2. 不直接进入高可信母样本层
3. 先补主体与复杂度依据
4. 再决定是否升为 A / B 级优先账户

## 6. 下一步

下一步建议按以下顺序继续推进：

1. 先从本批里挑每个主画像 2 到 3 家做强核验
2. 把通过核验的账户并入 `v0.2 高可信母样本`
3. 再继续扩第三批候选

这样可以让池子扩张，但不牺牲口径稳定性。
