# 外部目标客户池 v1.0 第七批放量候选池 v0.1

## 1. 文档目的

本文件继续扩展第七批放量候选，目标是沿当前已经压实的画像边界，把静态潜客总池继续稳定推大。

这一批仍保持两个约束：

1. 不为了冲规模而放松画像边界
2. 每个新增账户都必须能清楚说明“为什么入池”

## 2. 筛入原则

本批账户必须满足：

1. 属于零售消费、跨境电商、先进制造三条主线之一
2. 能映射到当前已成立画像
3. 有清晰可表达的入池理由
4. 已做明显同名主体排除
5. 不与当前已有潜客池账户重复

## 4. 本轮扩池结果

本轮新增第七批候选 `36` 家：

- 零售消费：14 家
- 跨境电商：10 家
- 先进制造：12 家

## 5. 当前意义

第七批扩池后，总池覆盖继续外延到：

- 商超连锁与区域型零售
- 家纺 / 厨电 / 冷冻食品等高 SKU 品牌消费品
- 工具、家居、出行等品牌出海和出口型企业
- 汽车零部件、热管理、光通信与新材料制造

这让三条主线都继续变厚，同时仍保持在既有画像边界内。
