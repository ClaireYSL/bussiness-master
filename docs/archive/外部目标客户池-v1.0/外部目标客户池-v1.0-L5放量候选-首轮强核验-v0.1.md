# 外部目标客户池 v1.0 L5 放量候选首轮强核验 v0.1

## 1. 文档目的

本文件从 [外部目标客户池-v1.0-总池汇总视图-v0.1.md](/Users/clairaipartner/.openclaw/workspace-main/bussiness-master/docs/外部目标客户池-v1.0-总池汇总视图-v0.1.md) 的 `L5-放量候选` 中，挑选第一批账户进入强核验。

目标：

- 验证第三批放量候选能否沿当前标尺集被继续压实
- 判断哪些 L5 账户可以升级为 `L3` 或 `L2`
- 避免 L5 长期停留在纯候选状态，导致总池结构失衡

## 2. 本轮核验对象

本轮选择以下 4 家：

- 贝泰妮集团股份有限公司
- 影石创新科技股份有限公司
- 海目星激光科技集团股份有限公司
- 公牛集团股份有限公司

选择原因：

- 覆盖零售消费、品牌出海、先进制造三条主线
- 都与现有高可信样本的画像距离较近
- 相对容易找到年报、招股书或较强公开披露

## 5. 本轮影响

本轮首轮强核验后：

- `影石创新` 可上移为 `高可信补充样本`
- `海目星` 可上移为 `中高可信补充样本`
- `贝泰妮` 可先上移为 `中高可信补充样本`
- `公牛集团` 暂不升级到补充样本层，继续保留在观察上浮状态

## 6. 当前结论

这轮说明：

1. `L5` 并不是纯收集箱，确实可以继续被压实。
2. 第三批放量候选中，已经开始出现可升级到补充样本层的账户。
3. 但 `L5` 的证据质量差异明显，仍需坚持“小步强核验”，不能整体抬升。

## 7. 下一步建议

下一步建议继续从 `L5` 中再挑 4 家：

- 影石创新已升级后，可转而优先核验：
  - 正浩 EcoFlow
  - DJI 大疆
  - 贝泰妮如补到官方全文后再复核
  - 海目星同画像相邻制造企业

并同步开始准备把已经升级的账户回写到总池汇总视图。
