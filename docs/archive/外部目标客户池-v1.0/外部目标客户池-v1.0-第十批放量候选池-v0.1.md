# 外部目标客户池 v1.0 第十批放量候选池 v0.1

## 1. 文档目的

本文件继续扩展第十批放量候选。

这一批的目标非常明确：

- 继续保持静态潜客池的高质量放量
- 在不引入动态机会判断的前提下，把总池规模正式推进到 `300+`

## 2. 筛入原则

本批账户必须满足：

1. 属于零售消费、跨境电商、先进制造三条主线之一
2. 能映射到当前已成立画像
3. 有清晰可表达的入池理由
4. 已做明显同名主体排除
5. 不与当前已有潜客池账户重复

## 4. 本轮扩池结果

本轮新增第十批候选 `36` 家：

- 零售消费：12 家
- 跨境电商：12 家
- 先进制造：12 家

## 5. 当前意义

第十批扩池后，总池继续覆盖到：

- 调味品、乳品、餐饮连锁等消费品与零售业态
- 服装、家居、材料与宠物用品等出口经营主体
- 工程机械、机床、智能装备与高端制造

这使总池在保持静态匹配逻辑的前提下，正式跨过 `300+` 规模目标。
