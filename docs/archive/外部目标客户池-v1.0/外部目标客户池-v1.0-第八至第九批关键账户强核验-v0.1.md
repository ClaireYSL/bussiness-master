# 外部目标客户池 v1.0 第八至第九批关键账户强核验 v0.1

## 1. 文档目的

本文件继续从第八批及相邻待核候选中挑选最值得上移的 6 家账户做强核验。

目标：

- 继续增厚高质量层
- 证明第八批之后的放量候选仍能稳定产出补充标尺
- 让总池从 `200+` 继续往 `300+` 推时，质量不塌

## 2. 本轮核验对象

本轮选择以下 6 家：

- 永辉超市股份有限公司
- 家家悦集团股份有限公司
- 波司登国际控股有限公司
- 卧龙电气驱动集团股份有限公司
- 芜湖伯特利汽车安全系统股份有限公司
- 中际旭创股份有限公司

选择原因：

- `永辉`、`家家悦`、`波司登` 代表零售消费里更成熟的连锁零售与品牌服饰画像
- `卧龙电驱`、`伯特利`、`中际旭创` 代表先进制造里更高复杂度的可复制样本

## 4. 本轮影响

本轮强核验后，可新增：

- `5` 家高可信补充样本
- `1` 家中高可信补充样本

新增上移账户为：

- 永辉超市
- 家家悦
- 波司登
- 卧龙电驱
- 伯特利
- 中际旭创

## 5. 当前结论

这轮说明：

1. 第七批和第八批里已经存在可稳定上移的零售与先进制造样本。
2. 商超零售、品牌服饰、汽车零部件、光通信制造这几类画像都可以继续加厚。
3. 当前方法仍然有效：不是“先做 300 家再说”，而是边放量、边上移、边校准。
