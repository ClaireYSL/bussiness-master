# 外部目标客户池 v1.0 第四至第六批关键账户强核验 v0.1

## 1. 文档目的

本文件从第四、第五、第六批放量候选中，挑选一批最值得提前压实的关键账户做强核验。

这一轮的目标不是平均核所有新增账户，而是优先把最有机会成为 `高可信补充样本` 的公司尽快上移，持续增厚高质量静态潜客池。

## 2. 本轮核验对象

本轮选择以下 6 家：

- 居然之家新零售集团股份有限公司
- 华宝新能科技股份有限公司
- 蓝思科技股份有限公司
- 欣旺达电子股份有限公司
- 宁德时代新能源科技股份有限公司
- 北方华创科技集团股份有限公司

选择原因：

- `居然之家` 代表大型家居零售平台型总部经营画像
- `华宝新能` 代表品牌出海型储能消费电子画像
- `蓝思科技`、`欣旺达` 代表消费电子链路上的复杂制造画像
- `宁德时代`、`北方华创` 代表先进制造里更高复杂度、更高标尺价值的样本

## 4. 本轮使用的公开依据类型

本轮核验主要依赖以下类型的强证据：

- 2024 年年度报告
- 官方网站公司简介 / 投资者关系材料
- 官方公开披露中的门店、工厂、业务分部、海外经营说明

当前结论以“画像成立”和“可作为补充标尺”作为判断目标，不把动态商机因素混入核验逻辑。

## 5. 本轮影响

本轮强核验后，可新增 `6` 家高可信补充样本：

- 居然之家
- 华宝新能
- 蓝思科技
- 欣旺达
- 宁德时代
- 北方华创

这会直接提升两件事：

1. `零售消费 / 跨境电商 / 先进制造` 三条主线的高质量标尺密度
2. 第四至第六批放量候选的“可上移速度”

## 6. 当前结论

这一轮说明：

1. 第四至第六批里已经有一批账户足够强，不应长期停留在放量候选层。
2. 对于大型平台零售、品牌出海、高端制造和多工厂制造，官方年报级证据已经足够支撑上移到 `L2`。
3. 当前更合理的节奏不是只堆新增数量，而是保持“每扩一批，就上移一批”的循环。
