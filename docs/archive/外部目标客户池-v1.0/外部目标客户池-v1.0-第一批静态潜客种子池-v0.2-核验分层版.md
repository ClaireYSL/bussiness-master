# 外部目标客户池 v1.0 第一批静态潜客种子池 v0.2 核验分层版

## 1. 文档目的

本文件基于 [外部目标客户池-v1.0-第一批静态潜客种子池-v0.1.md](/Users/clairaipartner/.openclaw/workspace-main/bussiness-master/docs/外部目标客户池-v1.0-第一批静态潜客种子池-v0.1.md) 做第一次 `核验分层`。

目标不是一次性把 27 家全部做成强证据账户，而是先分清：

- 哪些已经可以作为 `高可信母样本`
- 哪些已经方向成立，但还需要补官方或年报证据
- 哪些当前只适合保留在观察层

## 2. 核验分层规则

### `高`

满足以下至少两项：

- 主体可被官方官网或官方年报确认
- 画像关键复杂度可被官方资料或权威公开资料确认
- 与观远现有画像的映射关系较稳定

### `中`

满足以下任一项：

- 主体较清晰，但画像关键复杂度还缺一段强证据
- 有公开资料支撑，但不是最强官方来源
- 方向成立，但仍需要补集团 / 品牌 / 经营复杂度确认

### `待补`

存在以下情况之一：

- 当前只有弱公开信息或行业常识支撑
- 主体虽清晰，但画像匹配或切入点仍偏推断
- 需要补更多官网 / 年报 / 公开经营资料
