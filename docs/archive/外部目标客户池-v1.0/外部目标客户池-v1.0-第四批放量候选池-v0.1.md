# 外部目标客户池 v1.0 第四批放量候选池 v0.1

## 1. 文档目的

本文件在当前总池基础上继续做第四批放量扩展。

这一批的目标不是提升单个账户证据强度，而是继续 `高质量地扩大静态潜客总池的总量`，同时保持每个新增账户都有明确的入池理由。

## 2. 入池要求

本批账户必须满足以下条件：

1. 属于三条主线之一
2. 能映射到当前已定义画像
3. 有明确的入池理由
4. 已与合作名单做过明显同名主体排除

## 4. 本轮扩池结果

本轮新增第四批候选 `20` 家：

- 零售消费：9 家
- 跨境电商：5 家
- 先进制造：6 家

## 5. 当前意义

这批新增后，静态潜客总池的外延继续扩大，但仍保持了三个约束：

1. 每个账户都有明确画像归属
2. 每个账户都有明确入池理由
3. 每个账户都保持在静态层判断内，不引入动态机会逻辑
