# 外部目标客户池 v1.0 画像映射规则

## 1. 文档目的

本文件用于定义：

- 画像是什么
- 每类画像如何映射外部潜客
- 每类画像如何映射内部存量客户与案例资产
- 每类画像适合什么前线切入话题

本文件不承载全量公司名单，只定义 `persona_to_accounts_case_map_v1` 的规则。

## 2. 画像映射表定义

### 表名

`persona_to_accounts_case_map_v1`

### 粒度

- 一行代表一类画像

### 必含字段

- 画像名称
- 画像定义
- 外部筛选特征
- 不适用边界
- 代表性外部潜客
- 对应存量客户
- 对应案例 / 方案 / 场景包
- 推荐切入话题
- 推荐触达方式

## 3. 通用画像定义规则

每个画像必须同时由三类特征定义：

### 3.1 外部客观特征

必须覆盖：

- 行业 / 子行业
- 业务模式
- 经营复杂度
- 组织复杂度

### 3.2 JTBD 特征

必须写成业务任务，例如：

- 总部看穿门店经营健康度
- 多平台跨境做 T+1 利润分析
- 多工厂集团实现经营驾驶舱

不得只写：

- 数据乱
- 报表慢
- 想数字化

### 3.3 观远匹配特征

必须明确：

- 观远已有哪类客户样本
- 观远已有哪类案例或方案
- 为什么前线讲这个画像时是可信的

## 4. 三条主线的画像设计要求

## 4.1 零售消费主阵地

零售消费是 v1.0 的主阵地，应承担主要命中率验证任务。画像需要更细。

建议优先建设以下画像：

### 画像 A：多门店连锁零售

外部特征：

- 连锁零售 / 商超便利 / 连锁服务
- 多门店、多区域、总部强管理

JTBD：

- 总部经营透视
- 门店经营健康度
- 区域差异分析
- 一线动作闭环

观远匹配：

- 对应经营分析平台型方案
- 对应总部到区域到门店穿透类案例

### 画像 B：高 SKU 品牌消费品

外部特征：

- 品牌消费品
- SKU 多
- 渠道、库存、动销复杂

JTBD：

- 商品与库存优化
- 渠道与动销分析
- 业财供协同

观远匹配：

- 对应消费品增长分析和供应链协同类案例

### 画像 C：连锁餐饮 / 茶饮 / 咖啡

外部特征：

- 连锁餐饮 / 茶饮 / 咖啡
- 直营+加盟混合或区域扩张明显

JTBD：

- 门店经营透视
- 加盟管理
- 单店表现 / 菜品表现 / 区域赛马

观远匹配：

- 对应餐饮门店运营型方案与案例

## 4.2 跨境电商重点拓展

跨境电商是新增量方向，应优先抓中腰部高复杂度客户，而不是泛抓所有卖家。

建议优先建设以下画像：

### 画像 D：多平台多店铺品牌出海型

外部特征：

- 品牌出海
- 多平台、多店铺、多国家

JTBD：

- 市场洞察与选品
- 多平台精细化运营
- 海外业务经营驾驶舱

观远匹配：

- 对应跨境电商 ABM 物料和品牌出海类叙事

### 画像 E：供应链复杂的跨境经营型企业

外部特征：

- 海外仓 / 多国家履约 / 供应链复杂

JTBD：

- 供需平衡
- 库存优化
- T+1 利润分析
- 业财一体化

观远匹配：

- 对应跨境利润分析、运营协同和供应链类方案

## 4.3 先进制造重点拓展

先进制造是战略拓展方向，v1.0 应精选，不泛铺。

建议优先建设以下画像：

### 画像 F：多工厂离散制造集团

外部特征：

- 多工厂、多产线、多事业部
- 集团化经营明显

JTBD：

- 多工厂计划协同
- 生产达成与异常预警
- 集团经营驾驶舱

观远匹配：

- 对应经营型 BI、制造业驾驶舱类方案

### 画像 G：研产销协同复杂的技术型制造企业

外部特征：

- 技术型制造 / 消费电子 / 医疗器械 / CDMO
- 订单到交付链路长

JTBD：

- LTC
- 财务 / 生产 / 质量 / 存货联动
- 渠道效率与经营透明化

观远匹配：

- 对应经营协同、业财供协同、可做样板间的制造业方案

## 5. 映射关系填写规则

### 5.1 外部潜客映射

每个画像至少要列出：

- 5 到 10 个代表性外部目标公司

要求：

- 这些公司不是“同行业随机样本”
- 而是符合画像定义的代表性账户

### 5.2 存量客户映射

每个画像至少要列出：

- 2 到 5 个已服务过的内部样本客户

要求：

- 优先使用已经完成品牌/主体归一的客户
- 优先按“经营品牌 / 集团”映射，而不是按法人体后缀硬套

### 5.3 案例资产映射

每个画像至少要映射：

- 1 个标杆案例
- 1 类方案类型
- 1 类场景包或可复用话术锚点

## 6. 不适用边界规则

每个画像都必须写清楚 `不适用边界`。

示例：

- 不是所有零售公司都属于“多门店连锁零售”
- 不是所有跨境卖家都属于“多平台品牌出海型”
- 不是所有制造公司都属于“多工厂离散制造集团”

这部分是为了避免前线用行业名粗暴替代画像判断。

## 7. 触达建议映射规则

每个画像都应给出：

- 推荐切入话题
- 推荐触达方式
- 推荐案例锚点

示例：

- 多门店连锁零售
  - 切入：总部经营透视、门店动作闭环
  - 触达：电话+邮件 / 活动邀约
- 多平台跨境卖家
  - 切入：T+1 利润分析、供需与库存
  - 触达：邮件 / 活动 / 伙伴转介绍
- 多工厂制造集团
  - 切入：集团经营驾驶舱、LTC、计划协同
  - 触达：伙伴转介绍 / 定向拜访前置触达

## 8. 与其他文档的职责边界

- 本文件定义 `画像如何工作`
- 不定义公司级主表字段
- 不定义 A/B/C 打分细则
