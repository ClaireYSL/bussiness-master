# 外部目标客户池 v1.0 L5 放量候选第二轮强核验 v0.1

## 1. 文档目的

本文件继续对 `L5-放量候选` 做强核验，目标是进一步把第三批放量候选中的优质账户上移，避免总池长期停留在“候选多、提纯慢”的状态。

## 2. 本轮核验对象

本轮选择以下 4 家：

- 深圳市正浩创新科技股份有限公司
- 深圳市大疆创新科技有限公司
- 登康口腔护理用品股份有限公司
- 中控技术股份有限公司

选择原因：

- `正浩`、`大疆` 都是品牌出海型的强代表账户
- `登康` 属于高 SKU 品牌消费品画像的优质候选
- `中控技术` 属于技术型制造画像中较有代表性的公司

## 5. 本轮影响

本轮强核验后：

- `正浩 EcoFlow` 可上移为 `高可信补充样本`
- `中控技术` 可上移为 `高可信补充样本`
- `大疆` 可上移为 `中高可信补充样本`
- `登康` 可上移为 `中高可信补充样本`

## 6. 当前结论

这轮说明：

1. `L5` 中跨境品牌出海型的优质账户开始快速上移。
2. 技术型制造画像也可以继续从 `L5` 提炼出较强补充样本。
3. 对非上市公司或非典型信息披露公司，如 `大疆`，仍需保留证据等级意识，不能因为品牌强就直接视作最高可信层。
