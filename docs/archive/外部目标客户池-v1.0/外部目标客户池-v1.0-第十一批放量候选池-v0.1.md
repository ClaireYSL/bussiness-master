# 外部目标客户池 v1.0 第十一批放量候选池 v0.1

## 1. 文档目的

本文件继续扩展第十一批放量候选。

这一批不再机械追求“每批固定 36 家”，而是优先保证名单干净、画像稳定、理由清晰。

## 2. 筛入原则

本批账户必须满足：

1. 属于零售消费、跨境电商、先进制造三条主线之一
2. 能映射到当前已成立画像
3. 有清晰可表达的入池理由
4. 已做明显同名主体排除
5. 不与当前已有潜客池账户重复

本轮新增第十一批候选 `28` 家：

## 5. 当前意义

第十一批扩池后，总池继续覆盖：

- 烘焙、饮品、速冻、卤味等消费品牌
- 家居、材料、电池与控制类出口经营主体
- 重工装备、机器人、机床、智能物流与轨交电气制造

这使总池在保持高质量前提下继续外扩，而不是单纯堆量。
