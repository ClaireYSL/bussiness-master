# 外部目标客户池 v1.0 第一批静态潜客种子池 v0.1

## 1. 文档说明

本文件是 `external_target_account_pool_v1` 的第一批真实种子名单。

特点：

- 面向 `SDR / 市场 BD`
- 属于 `静态潜客池`
- 不是动态机会池
- 当前规模以 `种子验证` 为目标，不以数量为目标

说明：

- 本批名单已对照 `历年合作列表2026-02-23.xlsx` 做过 `明显同名主体排除`
- 但由于品牌别名、集团主体、子公司主体可能与合作名单存在不一致，仍需在后续批量扩池时继续复核

## 2. 字段说明

本名单先使用以下核心字段：

- 主线
- 目标账户归一主体
- 品牌名
- 一级/二级行业
- 业务模式
- 主画像
- 主 JTBD
- 存量客户参照
- 方案 / 案例匹配
- 静态优先级
- 推荐触达方式
- 推荐切入话题
- 推荐触达理由摘要
- 待验证项
