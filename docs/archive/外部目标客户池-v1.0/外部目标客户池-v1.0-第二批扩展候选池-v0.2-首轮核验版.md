# 外部目标客户池 v1.0 第二批扩展候选池 v0.2 首轮核验版

## 1. 文档目的

本文件对 [外部目标客户池-v1.0-第二批扩展候选池-v0.1.md](/Users/clairaipartner/.openclaw/workspace-main/bussiness-master/docs/外部目标客户池-v1.0-第二批扩展候选池-v0.1.md) 做第一轮强核验。

这轮不追求把第二批全部账户一次性做完，而是先挑选 4 家代表性账户，验证：

- 第二批扩展是否真的沿着高可信母样本的画像边界在增长
- 扩展账户能否通过官方 / 年报级证据被压实
- 哪些扩展账户可以升级为下一轮 `高可信补充样本`

## 2. 本轮核验对象

本轮选择以下 4 家做首轮强核验：

- 周大生珠宝股份有限公司
- 上海晨光文具股份有限公司
- 科沃斯机器人股份有限公司
- 迈为股份有限公司

选择原因：

- 分别覆盖零售消费、品牌消费品、跨境品牌出海、先进制造
- 都是第二批扩展池中较容易找到官方或年报级依据的代表账户

## 5. 当前影响

这轮首轮核验后，第二批扩展账户里已有 3 家可以明确上移：

- 周大生珠宝股份有限公司
- 上海晨光文具股份有限公司
- 科沃斯机器人股份有限公司

其中：

- 周大生、科沃斯可作为 `高可信补充样本`
- 晨光文具可作为 `中高可信补充样本`
- 迈为股份继续保留在 `中可信候选`

## 6. 下一步建议

下一步继续按同样方式再挑 4 到 6 家做强核验，建议优先：

- 水羊集团股份有限公司
- 致欧家居科技股份有限公司
- 绿联科技股份有限公司
- 杭可科技股份有限公司
- 中航光电科技股份有限公司

原则不变：

- 先压实少量扩展账户
- 再把通过核验的账户并入高可信补充样本层
- 不把第二批候选整体一次性抬升
