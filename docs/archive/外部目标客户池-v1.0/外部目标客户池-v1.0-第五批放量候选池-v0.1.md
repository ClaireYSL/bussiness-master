# 外部目标客户池 v1.0 第五批放量候选池 v0.1

## 1. 文档目的

本文件继续在既有画像边界内扩展第五批放量候选账户，目标是继续提升 `高质量静态潜客总池` 的总体规模。

## 2. 筛入原则

本批账户必须满足：

1. 属于零售消费、跨境电商、先进制造三条主线之一
2. 能映射到当前已成立画像
3. 有清晰可表达的入池理由
4. 已做明显同名主体排除

## 4. 本轮扩池结果

本轮新增第五批候选 `36` 家：

- 零售消费：14 家

- 先进制造：15 家

## 5. 当前意义

第五批扩池后，总池不再只集中在前几类典型品牌，而开始覆盖：

- 美妆个护
- 家居零售
- 潮玩文创
- 储能与消费电子出海
- 医疗设备
- 电子制造与自动化

但仍然保持在当前画像边界内。
