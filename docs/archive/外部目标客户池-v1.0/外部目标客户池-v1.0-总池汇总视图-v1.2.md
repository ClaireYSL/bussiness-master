### 2.4 当前判断字段口径

从这一版开始，围绕静态潜客池统一使用三字段：

1. `信息扎实度`
2. `ICP匹配概率`
3. `静态潜客记录成熟度`

说明：

- `信息扎实度` 回答“我们当前掌握的信息有多扎实”
- `ICP匹配概率` 回答“基于当前信息，我们判断其符合目标客群的概率有多高”
- `静态潜客记录成熟度` 回答“这条记录在静态池中的综合成熟度处于哪一层”
- `L1-L5` 仅对应第三个字段，不再单独代表匹配判断本身
