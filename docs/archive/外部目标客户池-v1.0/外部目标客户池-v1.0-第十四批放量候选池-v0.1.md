# 外部目标客户池 v1.0 第十四批放量候选池 v0.1

## 1. 文档目的

本文件用于承接“历史候选中尚未完成结构化迁移”的一批稳定对象。

这一批的策略是：

- 优先回收早期候选文档里边界较稳、但尚未落入结构化主表的对象
- 保持零售消费、跨境电商、先进制造三条主线均衡
- 继续保证入池理由和画像归属都清楚可解释

## 2. 筛入原则

本批账户必须满足：

1. 已在早期候选文档中出现过
2. 与当前结构化主表 canonical 账户不重复
3. 主线与画像都能稳定成立
4. 当前待验证项明确，但不构成阻断入池
