# 外部目标客户池 v1.0 静态评分与前线使用规则

## 1. 文档目的

本文件定义：

- v1.0 的静态评分维度
- A/B/C 的真实含义
- SDR / 市场 BD 的使用方式
- 禁止的误用方式

本文件不定义动态机会评分。

## 2. 评分的本质

v1.0 的评分本质是：

- `静态匹配优先级`

不是：

- 成交概率
- 项目成熟度
- 本季度收入预测

## 3. 评分对象

评分对象是 `静态潜客池中的公司级账户`。

动态机会字段即使存在，也不得参与 v1.0 主评分。

## 4. 五维静态评分

每个目标账户按以下五维评分：

### 4.1 行业与战略匹配

判断：

- 是否属于三条主线之一
- 是否属于当前重点行业与重点子行业

高分特征：

- 零售消费主阵地核心细分
- 跨境电商重点细分
- 先进制造重点细分

### 4.2 经营复杂度

判断：

- 是否存在多门店、多工厂、多平台、多区域、多组织层级等复杂性
- 是否复杂到值得平台化分析和解决方案切入

### 4.3 JTBD 类型匹配

判断：

- 是否存在明确可识别的业务任务
- 是否能映射到观远已有成熟场景

说明：

- 这里判断的是“任务类型成立”
- 不是“项目时机已确认”

### 4.4 观远优势

判断：

- 是否有近似客户
- 是否有可复用案例和行业方案
- 是否有成熟叙事和触达理由

### 4.5 标杆与复制价值

判断：

- 是否可复制到更多同类客户
- 是否适合作为行业样板间或标杆
- 是否有传播与战略意义

说明：

- `标杆价值` 可以在 v1.0 纳入静态评分
- `近期商机强度` 不得并入该维度

## 5. A/B/C 定义

## A 类

定义：

- 静态匹配强
- 画像归属明确
- 观远案例支撑充分
- 前线切入理由强

适用：

- SDR 优先触达
- 市场 BD 优先经营

## B 类

定义：

- 静态匹配成立
- 但存在部分待验证项
- 或案例支撑稍弱
- 或画像边界较宽

适用：

- 重点培育
- 跟随活动、内容、伙伴机会推进

## C 类

定义：

- 方向可能成立
- 但依据不足
- 或当前不适合首轮重点触达

适用：

- 保留观察
- 后续二次验证

## 6. 禁止的解释

以下解释在 v1.0 中是错误的：

- A 类 = 会成交
- B 类 = 暂时没机会
- C 类 = 无价值
- A/B/C = 项目成熟度
- A/B/C = AE 投入优先级的唯一依据

## 7. SDR 使用规则

SDR 主要使用：

- A 类
- 部分 B 类

SDR 在使用时关注：

- 推荐切入话题
- 推荐触达理由摘要
- 对应案例类型
- 对应存量客户样本
- 待验证项

SDR 不应假设：

- 名单中的公司已经存在预算
- 名单中的公司已经存在项目窗口

## 8. 市场 BD 使用规则

市场 BD 主要使用：

- A 类
- B 类

使用方式：

- 活动邀约名单
- 定向内容经营
- 行业经营名单
- 伙伴共拓目标池

市场 BD 在使用时关注：

- 主线
- 行业 / 子行业
- 画像标签
- 推荐触达方式
- 标杆与复制价值

## 9. 动态机会层的处理规则

v1.0 中可预留以下动态信息，但不得并入主评分：

- 活动参与
- 内容互动
- 伙伴引荐
- 销售触达反馈
- 公开项目或组织变化信号

这些内容只可：

- 写入预留字段
- 作为附加说明
- 为 v1.1 / v1.5 做准备

## 10. 错误使用边界

以下做法属于误用：

1. 用 v1.0 名单直接替代商机池
2. 用 A/B/C 直接替代 AE 投入优先级
3. 因缺少动态信号而把静态潜客剔除
4. 把动态机会层重新并入 v1.0 主模型
5. 因跨境和制造资料不如零售成熟，就强行要求三条主线同质完备
