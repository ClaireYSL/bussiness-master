如果用户要判断“为什么这个池子现在值得继续扩”，建议按这个顺序读：

1. 先看 [外部目标客户池-v1.0-入选标准与理由总览-v0.1.md](/Users/clairaipartner/.openclaw/workspace-main/bussiness-master/docs/外部目标客户池-v1.0-入选标准与理由总览-v0.1.md)
2. 再看各批放量候选文档中的 `入池理由`
3. 再看强核验文档中哪些公司已经被上移
4. 最后看本文件的总量、主线和分层状态

这样能同时回答：

- 为什么这些公司在池子里
- 为什么有些已经上移，有些还在候选层
- 为什么当前总池既在变大，也在变厚

## 7. 当前判断

当前最合理的推进节奏不是只做一件事，而是持续做两件事的循环：

1. `每轮新增 30-40 家` 高质量放量候选
2. `每轮强核 4-6 家` 最有代表性的账户

这样做有三个好处：

- 总量持续向 `300+` 推进
- 高质量层不会被候选层稀释
- 用户能清楚看到入池标准、入池理由和上移依据
