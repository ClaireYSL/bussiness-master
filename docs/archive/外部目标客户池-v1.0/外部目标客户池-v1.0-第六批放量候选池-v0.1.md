## 4. 本轮扩池结果

本轮新增第六批候选 `37` 家：

- 先进制造：20 家

## 5. 当前意义

第六批扩池后，总池开始进一步覆盖：

- 清洁家电品牌出海
- 储能与消费电子出海
- 户外消费品牌
- 新能源材料
- 半导体设备
- 高端电子制造

这让先进制造和跨境电商两条线的总量都明显更接近目标池规模。
