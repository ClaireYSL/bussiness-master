# 外部目标客户池 v1.0 L4 中可信候选首轮强核验 v0.1

## 1. 文档目的

本文件从当前 `L4-中可信候选` 中挑选最接近优先触达池的账户，做第一轮强核验。

目标：

- 把已经方向明确、但证据还差一口气的账户尽快上移
- 直接增厚 `L2 / L3`
- 比继续铺更多新候选更快提升高质量名单密度

## 2. 本轮核验对象

本轮选择以下 4 家：

- 海澜之家集团股份有限公司
- 良品铺子股份有限公司
- 赛维时代科技股份有限公司
- 华凯易佰科技股份有限公司

选择原因：

- 都已在现有池子中出现
- 都与现有画像边界高度贴合
- 都已能找到较强公开披露或年报级依据

## 5. 本轮影响

本轮强核验后：

- `良品铺子` 升为 `L2-高可信补充样本`
- `赛维时代` 升为 `L2-高可信补充样本`
- `海澜之家` 升为 `L3-中高可信补充样本`
- `华凯易佰` 升为 `L3-中高可信补充样本`

## 6. 当前结论

这轮说明：

1. `L4` 里已经存在一批非常接近优先触达池的账户。
2. 通过小步强核验，可以更快提升高质量潜客名单密度。
3. 对零售消费和跨境电商，这种“先从 L4 上移”比继续无差别扩 L5 更有效。

## 7. 下一步建议

下一步建议继续从 `L4` 中再挑 3 到 4 家：

- 茶百道
- 森马
- 歌尔股份
- 无锡先导智能

并同步回写总池汇总视图与优先触达池。
