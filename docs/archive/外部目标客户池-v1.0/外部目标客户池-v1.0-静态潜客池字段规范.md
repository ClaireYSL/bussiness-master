# 外部目标客户池 v1.0 静态潜客池字段规范

## 1. 文档目的

本文件定义 `external_target_account_pool_v1` 的字段结构、字段含义、填写规则和空值策略。

本文件只服务 `静态潜客池`，不定义动态机会判断模型。

## 2. 主表定义

### 表名

`external_target_account_pool_v1`

### 粒度

- 一行代表一个 `公司级目标账户`
- 优先以 `经营品牌 / 经营集团归一后` 的公司主体作为记录对象

### 去重原则

1. 同一品牌、集团、签约主体存在多个名称时，优先保留一条 `canonical` 记录
2. 当签约主体是科技公司、电商公司、供应链公司、分公司时，不直接按法人体后缀建独立画像，优先追溯至经营品牌或集团
3. 允许保留 `主体全称`、`品牌名`、`集团名` 三层字段，但主表记录仍按一个目标账户去重

## 3. 字段分组

字段分为六组：

- A. 识别字段
- B. 画像字段
- C. JTBD 字段
- D. 观远匹配字段
- E. 触达建议字段
- F. 动态机会预留字段

## 4. 字段定义

## A. 识别字段

### `account_canonical_name`

- 含义：目标账户归一后的主体名称
- 类型：文本
- 必填：是
- 规则：优先使用最适合市场识别和内部去重的公司级主体名

### `brand_name`

- 含义：市场常用品牌名或业务名
- 类型：文本
- 必填：否
- 规则：如品牌与主体名高度一致，可重复填写

### `group_name`

- 含义：归属集团或经营集团
- 类型：文本
- 必填：否
- 规则：用于连接品牌与主体；找不到时可空

### `website`

- 含义：官网链接
- 类型：文本
- 必填：否
- 规则：填主站链接；没有可靠官网时可空

### `hq_city`

- 含义：总部城市
- 类型：枚举文本
- 必填：否

### `province`

- 含义：总部省份
- 类型：枚举文本
- 必填：否

### `source_note`

- 含义：该记录的主要来源说明
- 类型：文本
- 必填：是
- 规则：记录候选池来源或主要核验来源，例如“官网+行业榜单+案例相邻品牌”

## B. 画像字段

### `primary_track`

- 含义：主线归属
- 类型：枚举
- 必填：是
- 可选值：
  - `零售消费`
  - `跨境电商`
  - `先进制造`

### `industry_l1`

- 含义：一级行业
- 类型：枚举文本
- 必填：是

### `industry_l2`

- 含义：二级行业
- 类型：枚举文本
- 必填：是

### `business_model`

- 含义：业务模式
- 类型：枚举文本
- 必填：是
- 示例：
  - 品牌零售
  - 连锁经营
  - 品牌消费品
  - 品牌出海
  - 多平台卖家
  - 离散制造
  - 技术型制造

### `persona_tag`

- 含义：主要客群画像标签
- 类型：文本
- 必填：是
- 规则：每条记录只填一个主画像；附加画像放在补充说明中处理

### `company_scale_band`

- 含义：公司规模分层
- 类型：枚举
- 必填：否
- 可选值：
  - `小型`
  - `中型`
  - `中大型`
  - `大型`
  - `未确认`

### `complexity_tag`

- 含义：经营复杂度标签
- 类型：文本
- 必填：是
- 示例：
  - 多门店多区域
  - 多平台多店铺多国家
  - 多工厂多事业部
  - 高 SKU 高库存压力

## C. JTBD 字段

### `primary_jtbd`

- 含义：主要业务任务
- 类型：文本
- 必填：是
- 规则：必须写成任务，不写泛痛点

### `secondary_jtbd`

- 含义：次要业务任务
- 类型：文本
- 必填：否

### `transformation_stage_tag`

- 含义：转型阶段标签
- 类型：枚举文本
- 必填：否
- 示例：
  - 数字化补基础
  - BI 升级
  - AI+BI 探索
  - 出海扩张
  - 集团化经营升级

### `trigger_type_hint`

- 含义：可推断触发类型
- 类型：文本
- 必填：否
- 说明：这是 `触发类型判断`，不是 `动态机会已确认`

### `current_business_problem`

- 含义：当前可推断业务问题
- 类型：文本
- 必填：是
- 规则：一句话描述为什么这类客户会对观远的话题敏感

## D. 观远匹配字段

### `case_type_match`

- 含义：对应案例类型
- 类型：文本
- 必填：是
- 示例：
  - 连锁零售经营分析
  - 跨境 T+1 利润分析
  - 制造业经营驾驶舱

### `existing_customer_reference`

- 含义：对应存量客户样本
- 类型：文本
- 必填：是
- 规则：优先填 1 到 3 个最贴近样本

### `solution_match`

- 含义：对应行业方案
- 类型：文本
- 必填：是

### `scenario_pack_match`

- 含义：对应场景包
- 类型：文本
- 必填：否

### `ai_bi_fit`

- 含义：AI+BI 匹配判断
- 类型：枚举
- 必填：是
- 可选值：
  - `高`
  - `中`
  - `低`

### `showcase_potential`

- 含义：样板间 / 标杆潜力
- 类型：枚举
- 必填：否
- 可选值：
  - `高`
  - `中`
  - `低`
  - `未判断`

## E. 触达建议字段

### `static_priority`

- 含义：静态匹配优先级
- 类型：枚举
- 必填：是
- 可选值：
  - `A`
  - `B`
  - `C`

### `preferred_outreach_channel`

- 含义：优先触达方式
- 类型：枚举文本
- 必填：是
- 可选值：
  - 电话
  - 邮件
  - 活动邀约
  - 伙伴转介绍
  - 电话+邮件
  - 活动+伙伴

### `opening_topic`

- 含义：推荐切入话题
- 类型：文本
- 必填：是

### `reachout_reason_summary`

- 含义：推荐触达理由摘要
- 类型：文本
- 必填：是
- 规则：控制在 1 到 2 句话，供前线直接使用

### `validation_gap`

- 含义：待验证项
- 类型：文本
- 必填：否
- 规则：没有待验证项时可空

## F. 动态机会预留字段

以下字段在 v1.0 中允许为空，且不得参与静态优先级主判断：

### `dynamic_signal_status`

- 含义：动态信号状态
- 类型：枚举
- 可选值：
  - `未采集`
  - `无明显信号`
  - `存在弱信号`
  - `存在强信号`

### `recent_trigger_event`

- 含义：近期事件信号
- 类型：文本

### `engagement_signal`

- 含义：活动或内容互动信号
- 类型：文本

### `referral_signal`

- 含义：伙伴推荐或关系引荐信号
- 类型：文本

### `sales_feedback_status`

- 含义：销售触达反馈状态
- 类型：文本

## 5. 最小前线可用信息集

每家公司至少必须补齐以下字段：

- `account_canonical_name`
- `brand_name`
- `primary_track`
- `industry_l1`
- `industry_l2`
- `business_model`
- `persona_tag`
- `complexity_tag`
- `primary_jtbd`
- `current_business_problem`
- `case_type_match`
- `existing_customer_reference`
- `solution_match`
- `ai_bi_fit`
- `static_priority`
- `preferred_outreach_channel`
- `opening_topic`
- `reachout_reason_summary`
- `source_note`

## 6. 空值策略

### 允许为空

- `group_name`
- `website`
- `hq_city`
- `province`
- `company_scale_band`
- `secondary_jtbd`
- `transformation_stage_tag`
- `trigger_type_hint`
- `scenario_pack_match`
- `showcase_potential`
- `validation_gap`
- 全部动态机会预留字段

### 不允许为空

- 主体识别字段中的 `account_canonical_name`
- 画像主字段
- 主 JTBD
- 观远匹配主字段
- 静态优先级与触达建议主字段
