## 5. 前线使用建议

### 5.1 SDR 优先顺序

优先推荐：

1. 零售消费的 `L1 + L2`
2. 跨境电商的 `L1 + L2`
3. 零售消费与跨境电商中的 `L3`

说明：

- 先进制造更适合结合伙伴、行业关系或定向触达
- 不建议把先进制造作为冷启动外呼的第一优先组

### 5.2 市场 BD 优先顺序

优先推荐：

1. 跨境电商 `L2 + L3`
2. 零售消费 `L1 + L2 + L3`
3. 先进制造 `L1 + L2 + L3`

说明：

- 跨境电商和先进制造更适合行业活动、白皮书、伙伴共拓和定向内容经营
