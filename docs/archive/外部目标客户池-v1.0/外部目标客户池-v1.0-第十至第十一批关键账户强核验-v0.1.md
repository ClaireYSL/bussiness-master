# 外部目标客户池 v1.0 第十至第十一批关键账户强核验 v0.1

## 1. 文档目的

本文件继续从第十批及相邻高价值候选中挑选最值得上移的账户做强核验。

目标：

- 继续增厚高质量层
- 验证食品品牌、服饰零售、品牌出海、工程机械和汽车电子画像的稳定性
- 在总池已跨过 `300+` 后，继续提升静态池的可解释性和可复制性

## 2. 本轮核验对象

本轮选择以下 6 家：

- 特步（中国）有限公司
- 三只松鼠股份有限公司
- 中炬高新技术实业（集团）股份有限公司
- 华利实业集团股份有限公司
- 三一重工股份有限公司
- 惠州市德赛西威汽车电子股份有限公司

选择原因：

- `特步`、`三只松鼠`、`中炬高新` 代表零售消费里更成熟的品牌零售和高 SKU 品牌消费品画像
- `华利集团` 代表复杂跨境经营型企业里的高质量边界样本
- `三一重工`、`德赛西威` 代表先进制造里工程机械与汽车电子两类高价值样本

本轮强核验后，可新增：

- `5` 家高可信补充样本
- `1` 家中高可信补充样本

新增上移账户为：

- 特步
- 三只松鼠
- 中炬高新
- 华利集团
- 三一重工
- 德赛西威

## 5. 当前结论

这轮说明：

1. 零售消费里食品品牌和服饰品牌都可以继续稳定上移。
2. 跨境电商里复杂跨境经营型企业不必只靠消费电子样本支撑。
3. 先进制造里工程机械与汽车电子画像开始变厚，后续扩池会更稳。
