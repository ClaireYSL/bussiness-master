# 潜在客群理想客户画像设计框架 v1

## 一、目的

这份框架的目标，不是直接输出潜在客户名单，而是先建立一套稳定、可复用的 `理想客户画像（ICP）设计方法`，用于后续：

- 统一潜在客群筛选口径
- 避免“行业名词化”“凭经验拍脑袋”
- 把历史案例、合作客户、战略方向、售前打法整合进同一套分析框架
- 为后续客户底表、潜客名单、ABM分层、优先级排序提供统一依据

## 二、核心原则

### 1. 不把“行业”当作唯一标准

行业只能回答“这家公司属于哪个赛道”，不能回答：

- 它是否真的有复杂经营问题
- 它为什么现在会买
- 观远是否真的适合做

因此，行业只能作为第一层标签，不能作为最终判断依据。

### 2. 区分三类不同性质的特征

潜在客户分析里，至少要区分三类特征：

- `外部客观特征`
  - 客户本身是什么样
- `观远匹配特征`
  - 观远是否适合服务它
- `JTBD/购买驱动特征`
  - 它为什么会产生购买行为

这三类特征不能混写，否则会出现“看起来像 ICP，但实际上打不动”或“有需求，但当前观远不具备优势”的误判。

### 3. ICP 不是单一画像，而是分主线画像

结合当前业务背景，建议至少拆成三条主线：

- `零售消费主阵地 ICP`
- `跨境电商重点拓展 ICP`
- `先进制造重点拓展 ICP`

原因是三类客户在以下方面存在显著差异：

- 经营复杂度来源不同
- 典型 JTBD 不同
- 决策链不同
- 观远现有优势不同
- 样板间与标杆价值不同

## 三、ICP 设计的七个视角

## 1. 基础画像视角

回答：`这是什么样的公司`

关注字段：

- 行业
- 子行业
- 业务模式
- 公司规模
- 地域/国家/区域
- 组织结构
- 多品牌/多事业部/多法人情况

这一层的作用：

- 做初筛
- 形成行业池
- 用于后续分组和对照

这一层的局限：

- 区分度不够
- 很多“看起来像”的客户，未必有真实需求

## 2. 经营复杂度视角

回答：`它是否天然需要更强的数据产品与解决方案`

关注字段：

- 多门店 / 多工厂 / 多仓 / 多店铺
- 多渠道 / 多平台 / 多国家 / 多币种
- SKU复杂度
- 计划、生产、库存、销售联动复杂度
- 组织协同复杂度
- 总部到区域到一线的管理半径

这一层的意义：

- 比行业更能判断真实需求强度
- 是识别“业务复杂度足够高、值得上系统”的关键层

## 3. 数字化成熟度视角

回答：`它现在处于什么数字化阶段`

关注字段：

- 主要依赖 Excel / 手工报表
- 已上 BI，但业务用不起来
- 已有数仓/数据中台，但价值释放不足
- 已有大量报表，但重复问数/临时取数仍然很多
- 开始从 BI 往 AI+BI 升级
- 是否有 IT / 数据 / 分析团队

这一层的意义：

- 决定切入方式
- 决定是先卖“基础整合”，还是卖“经营分析升级”，还是卖“AI+BI”

## 4. JTBD 视角

回答：`它真正想完成什么业务任务`

这一层必须避免写成泛泛的“痛点”，而要写成业务任务。

示例：

- 总部要看穿门店经营健康度并推动动作闭环
- 加盟扩张中要降低选品和补货决策门槛
- 多平台跨境业务需要做 T+1 利润分析
- 多工厂制造需要实现订单到交付的可视化协同
- 医疗器械企业要看穿代理商到医院终端的真实消耗
- 高层需要统一经营驾驶舱和异常预警

这一层的意义：

- 是购买驱动的核心
- 决定用什么价值主张、讲什么案例、推什么方案

## 5. 观远匹配度视角

回答：`观远是不是适合服务它`

这层不是客户天然特征，而是“客户 x 观远”的关系特征。

关注字段：

- 是否有可复用案例
- 是否有成熟行业方案
- 是否有对应场景包
- 是否已有 Demo / ABM物料 / 标杆故事
- 当前产品能力是否能接住
- 是否需要生态伙伴补位
- 是否适合作为样板间
- 是否适合作为 AI 新产品案例

这一层的意义：

- 防止把“有需求”误判成“观远现阶段一定适合”
- 直接决定优先级

## 6. 购买条件视角

回答：`它有没有现实购买可能性`

关注字段：

- 是否存在明确业务 owner
- 是否有预算能力
- 是否有高层驱动或项目驱动
- 是否处于组织变化或业务转型窗口期
- 是否刚经历扩张、加盟化、出海、IPO、事业部重组
- 是否已有明确项目线索
- 是否具备较强标杆意识

这一层的意义：

- 区分“长期看好”与“短期可转化”

## 7. 战略价值视角

回答：`即使不一定最好卖，它是否值得重点经营`

关注字段：

- 是否属于公司战略行业
- 是否具备区域突破意义
- 是否具备标杆传播价值
- 是否可复制到更多客户
- 是否能沉淀成新行业方法论
- 是否能支撑生态合作
- 是否能承载 AI+BI 新叙事

这一层的意义：

- 帮助识别“战略型客户”
- 避免只看短期转化而忽略长期价值

## 四、画像设计的五大字段组

为方便后续落表，建议将所有画像字段收敛为五大字段组：

## A. 公司是什么

- 行业
- 子行业
- 业务模式
- 公司规模
- 区域
- 组织结构

## B. 业务为什么复杂

- 经营复杂度
- 数据复杂度
- 协同复杂度
- 渠道/门店/工厂/店铺复杂度

## C. 为什么现在会买

- JTBD
- 当前阶段
- 关键触发事件
- 当前痛点强度

## D. 为什么观远能赢

- 案例匹配
- 方案匹配
- 产品匹配
- 生态补位可能性
- 现有物料完备度

## E. 为什么值得优先做

- 成交概率
- 客单潜力
- 复制价值
- 标杆价值
- 战略价值

## 五、三条主线 ICP 的设计差异

## 1. 零售消费主阵地 ICP

### 重点关注的外部特征

- 多门店
- 多区域
- 多渠道
- 多商品 / 多SKU
- 多品牌或多事业部
- 总部管理半径大

### 重点关注的 JTBD

- 门店经营分析
- 商品与库存优化
- 会员与营销分析
- 渠道与区域经营差异分析
- 一线督导 / 店长 / 导购的数据动作闭环

### 重点关注的观远匹配点

- 现有案例最密集
- 方案最成熟
- BI+AI 一线应用叙事更容易成立
- 更容易做成样板间和标杆案例

### 典型 ICP 描述

适合观远的零售消费客户，通常不是“普通零售公司”，而是：

- 经营复杂度高
- 决策频率高
- 管理半径大
- 已经感受到经验管理失效
- 需要从总部到一线的数据能力下沉

## 2. 跨境电商重点拓展 ICP

### 重点关注的外部特征

- 多平台 / 多店铺 / 多国家
- 海外仓 / 跨境物流链路复杂
- 多币种 / 多税制
- 以品牌出海或精品卖家模式为主
- 一般已有内部 IT 或数据能力

### 重点关注的 JTBD

- 市场洞察与选品
- 多平台精细化运营
- 供需平衡与库存管理
- T+1 利润分析
- 业财一体化

### 重点关注的观远匹配点

- 2025 已经出现明显增长
- 已有 ABM 物料
- 已有 Top 客户案例
- 更适合中腰部高复杂度客户

### 典型 ICP 描述

适合观远的跨境电商客户，通常是：

- 年销售额达到一定规模
- 内部具备 IT / 数据团队
- 不是只需要一个报表，而是需要经营、供应链和财务协同
- 正处于从粗放增长转向精细化经营阶段

## 3. 先进制造重点拓展 ICP

### 重点关注的外部特征

- 多工厂 / 多产线 / 多事业部
- 订单到交付链路长
- 系统多、组织复杂
- 研产销协同要求高
- 有IPO、全球化、集团化、渠道化等变化

### 重点关注的 JTBD

- 订单到回款的经营穿透
- 多工厂计划达成与生产协同
- 供应商协同与库存风险控制
- 财务、生产、质量、存货一体化经营驾驶舱
- 渠道效率与技术品牌协同

### 重点关注的观远匹配点

- 适合从“经营型BI”切入，而不是去替代MES/SCADA
- 需要样板间和标杆客户支撑
- 某些项目需要生态伙伴补位
- 更适合经营复杂度高的离散制造/技术型制造客户

### 典型 ICP 描述

适合观远的先进制造客户，通常是：

- 不是单纯追求工厂可视化
- 而是希望通过数据打通经营协同、产销协同和管理透明度
- 高层有较强经营管控诉求
- 愿意把数字化作为管理升级抓手

## 六、建议增加的综合分析视角

除你已经提到的三类特征外，还建议增加以下几个视角：

## 1. 转型阶段视角

很多需求并不是由行业决定，而是由“阶段变化”决定。

例如：

- 直营转加盟
- 单品牌转多品牌
- 国内扩张转全球化
- 手工报表转系统化
- BI阶段转 AI+BI阶段
- 冲击 IPO 或集团化管控升级

这是识别“为什么现在会买”的关键视角。

## 2. 管理半径视角

本质上衡量的是：

- 总部能否真正看穿区域和一线
- 决策是否还停留在经验与局部视角

在零售消费、跨境电商、先进制造里，这一视角都非常重要。

## 3. 组织推动力视角

有些客户有问题，但没人能推动；有些客户问题还没完全爆发，但老板或核心部门已经在推动。

因此建议单独看：

- 老板驱动
- 业务部门驱动
- 财务驱动
- IT/数据团队驱动
- 售前能否快速找到 owner

## 4. 标杆传播潜力视角

这不是所有厂商都会专门看的一层，但对观远很重要。

建议单独标记：

- 是否可实名传播
- 是否具备行业代表性
- 是否有可参观性
- 是否能支持视频、白皮书、直播、活动、样板间
- 是否能承载 AI+BI 新产品叙事

## 5. 生态协同视角

尤其在先进制造和部分跨境电商场景里，需要看：

- 是否需要 SAP / ERP / 大屏 / 填报 / 集成伙伴配合
- 是否已有生态伙伴触点
- 是否适合通过伙伴联合突破

## 七、建议的 ICP 打分框架

建议后续在客户底表中，对每个客户按五类分项打分：

## 1. 行业与战略匹配分

- 是否属于主阵地或重点拓展行业
- 是否符合年度战略方向

## 2. 经营复杂度分

- 是否复杂到值得上系统
- 是否存在明显协同难题

## 3. JTBD 强度分

- 业务任务是否明确
- 是否存在强购买驱动

## 4. 观远优势分

- 案例、方案、产品、物料是否成熟
- 是否已有样板间或近似客户

## 5. 商机与战略价值分

- 近期成交可能性
- 客单潜力
- 标杆价值
- 可复制价值

## 八、建议的工作顺序

在正式筛客户前，建议按以下顺序推进：

1. 先固化统一字段框架
2. 为三条主线分别定义 ICP
3. 设计分项评分标准
4. 再把合作客户与案例映射到这套框架
5. 最后才开始筛潜在客户名单

## 九、下一步输出建议

基于这份框架，下一步建议直接产出两份内容：

- `潜客分析底表字段设计 v1`
  - 明确后续每个客户要填哪些字段
- `三大主线 ICP 定义 v1`
  - 分别输出零售消费、跨境电商、先进制造的理想客户画像模板

这样做完之后，再动手筛客户名单，效率会高很多，而且结论更稳。
