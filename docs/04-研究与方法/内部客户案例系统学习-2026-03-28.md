## 四、从内部材料看到的解决方案模式

内部材料比外部 PR 更清楚地暴露了你们常卖的方案模式，大体可以归成 6 类：

### 1. 经营分析平台型

- 典型材料：全家、鲜丰水果、气味图书馆、六桂福、北国珠宝、柒牌
- 核心卖点：统一口径、经营驾驶舱、业务自助分析、总部到区域到门店穿透
- 适用客户：多门店、多品牌、多区域、管理层经营复盘频繁的企业

### 2. 渠道/商品/电商增长型

- 典型材料：王小卤、宝洁、联合利华、森马电商、珀莱雅、自然堂、倍思
- 核心卖点：商品结构、渠道表现、促销投放、私域转化、全渠道增长
- 适用客户：品牌消费品、DTC 品牌、品牌电商、内容驱动品牌

### 3. 连锁餐饮门店运营型

- 典型材料：蜜雪冰城、COCO、德克士、遇见小面、张亮麻辣烫、老娘舅、夸父炸串、赛百味
- 核心卖点：门店经营透视、加盟管理、区域差异分析、菜品/单品分析、门店异常预警
- 适用客户：连锁餐饮、茶饮、咖啡、快餐、加盟体系品牌

### 4. 业财供协同型

- 典型材料：海天味业、五粮液、Fila 供应链、LLLM 采销供应链、秋田满满、吉家宠物
- 核心卖点：财务分析、供应链分析、库存优化、计划协同、生产与交付联动
- 适用客户：SKU 复杂、库存压力大、订单和生产链路长的企业

### 5. BI + 数仓 / 数据底座型

- 典型材料：蜜雪冰城、快乐蜂、珀莱雅、babycare、地素
- 核心卖点：从数据底座、主题域、指标体系到应用层整体推进
- 适用客户：已有一定数据基础，但分散、响应慢、业务用不起来的企业

### 6. BI + AI / 智能洞察型

- 典型材料：锅圈、自然堂、美妆个护典型案例、珀莱雅
- 核心卖点：问数、智能洞察、自动归因、自然语言交互、管理层智能决策
- 适用客户：已有 BI/数仓基础，下一步想做 AI 数据应用升级的客户

## 四点五、从长方案全文看到的底层卖法

对页数最高、关键词最密的长方案全文复核后，可以看到你们的售前骨架高度一致：

### 1. 先讲现状与痛点

- 多系统、多手工表、数据分散
- 业务口径不一致
- Excel 二次加工重
- 业务报表响应慢
- 业务用数依赖 IT / 分析师

### 2. 再讲整体蓝图

- 数据接入与整合
- 轻数仓/企业级数仓
- 指标体系与数据标准
- BI 分析平台
- 数据门户 / 驾驶舱 / 预警 / 移动端
- 客户成功服务与推广体系

### 3. 最后落到行业场景包

- 零售/鞋服：人货场、门店、导购、会员、商品、库存、补货
- 餐饮/茶饮：门店经营、加盟管理、单店表现、区域赛马、菜品与会员
- 消费品：渠道、经销、动销、费销、市场、供应链、需求计划
- 电商：平台、商品、流量、投放、私域、履约

### 4. 并且反复强调“让业务用起来”

- 不只卖技术，不只卖看板
- 强调业务自助、数据文化、推广机制、分角色视图
- 说明你们真正能复制的，不只是产品能力，还有“数据运营落地方法论”

## 五、对潜在客群挖掘的直接启发

### 第一优先级：品牌消费品与零售连锁

- 这是材料密度最高、打法最成熟、可复用程度最高的一类。
- 重点行业：
  - 美妆个护
  - 食品饮料
  - 鞋服配饰
  - 母婴宠物
  - 3C 家电
  - 品牌零售
  - 商超便利

### 第二优先级：连锁餐饮、茶饮、咖啡

- 案例足够密，方案模式清晰，且业务语言非常统一。
- 重点找：
  - 多门店直营+加盟混合品牌
  - 区域扩张中的连锁品牌
  - 对总部到门店穿透管理有强诉求的餐饮集团

### 第三优先级：业财供协同要求高的品牌商和制造企业

- 不是单纯工业制造，而是“经营和供应链都复杂”的企业。
- 重点找：
  - 多 SKU
  - 多工厂/多仓
  - 订单驱动生产
  - 高库存压力
  - 高渠道复杂度

### 第四优先级：已具备数据基础、准备做 BI+AI 升级的客户

- 这一类适合从“原有 BI 用不起来”或“已有报表但无法智能洞察”切入。
- 重点找：
  - 已有数据团队
  - 已建数仓或数据中台
  - 高层对 AI 应用有明确诉求
  - 内部存在大量临时取数和重复问数需求

- 从外部案例到内部案例，结论是一致的：你们最强的市场并不是泛 BI，而是 `AI+BI + 行业方案` 在消费零售、连锁经营、品牌消费品中的系统打法。
- 内部材料进一步证明，你们已经具备成熟的“方案模板库”，尤其适合反推潜在客群，而不只是做历史回顾。

## 七点五、用户补充的战略背景

用户明确补充了当前业务优先级：

- `零售消费` 是当前客群主阵地
- `跨境电商` 是 2026 年重点拓展行业
- `先进制造` 是 2026 年重点拓展行业

这会直接影响后续潜客分析的优先级排序：

- 第一层排序不能只按历史案例密度自然外推
- 需要同时结合：
  - `现有优势主阵地`
  - `2026 战略增量方向`
  - `是否已有可迁移案例与方案模板`

因此，后续潜客分析建议按以下逻辑展开：

1. `零售消费`
   - 作为主阵地，优先做精细分层和可复制客群扩展
2. `跨境电商`
   - 作为重点拓展行业，优先识别与现有消费品/品牌零售能力相邻的客户
3. `先进制造`
   - 作为重点拓展行业，优先识别经营复杂度高、增长快、具备经营型 BI 切入点的客户

## 十、从 Markdown 补充材料得到的新认知

### 1. 你们内部已经明确区分两种案例价值

从启动会纪要看，内部其实已经把案例分成两类：

- `案例包装`
  - 把已成交客户整理成可传播、可复用、可讲给潜客听的成功故事
- `场景共创`
  - 不是复述客户原话，而是深挖真实业务动机，抽象成可复制场景

这说明后续潜客分析不能只列“客户名单”，还要给每个行业画像绑定“可讲故事”与“可做场景”两套资产。

### 2. 真实需求经常和客户口头表达不同

启动会与来伊份场景文档都反复证明一个原则：

- 客户说“我要库存调拨”
- 真需求可能是“我要支撑加盟扩张下的选品能力”

来伊份文档把这个逻辑拆得很清楚：

- 表面需求：库存调拨、智能补货、巡店看数
- 真实动机：直营转加盟后，新店主缺乏选品能力，需要用数据能力降低加盟门槛
- 真正可卖的东西：区域适配、智能推荐、库存风险预警、巡店洞察、门店动作建议

这对潜客挖掘有直接影响：

- 不能按“客户提了什么功能”筛选潜客
- 应按“客户处于什么经营转型阶段”筛选潜客

### 3. 一线场景是新一轮 AI+BI 的重要突破口

ChatBI 一线应用文档提供了很强的信号：

- 你们不是只想给总部和分析师卖 AI
- 而是在尝试把数据能力下沉给督导、店长、业务员、加盟商等一线角色

高频场景包括：

- 巡店前的任务清单生成
- 现场门店对标分析
- SKU 结构差异与缺货诊断
- 终端执行跟踪
- 现场即时问数与异常归因

这意味着潜客画像里，应新增一类明确标签：

- `一线动作密集型企业`
  - 典型包括零售、鞋服、快消分销、连锁餐饮、加盟体系品牌

### 4. 出海案例说明你们的能力不只停留在中国本土

东南亚案例集至少说明三点：

- 蜜雪冰城这类万店加盟连锁的打法，已被你们包装为国际化标杆
- 安踏这类多品牌、多区域、供应链驱动型集团，也被定义成可输出到海外业务的数据能力模板
- 内部已经开始把这些案例转成英文/双语资产，说明你们在尝试把能力从“行业方案”进一步升级为“跨区域可复制方案”

这对潜客分析的意义是：

- 对国内客户，可以优先识别“有海外业务/跨境业务”的品牌集团
- 这类客户更容易接受“集团级数据治理 + 海外业务延展”的价值主张

### 5. 制造业案例显示你们也在形成“经营型BI”叙事

昊志机电案例不是单纯讲生产报表，而是在讲：

- 从财务、生产、质量、存货四大域重构经营驾驶舱
- 从手工报表、口径不一致、追溯困难走向端到端价值链管理
- BI 不只是工具，而是管理模式标准化和复制的抓手

这表明制造业方向里，你们真正有机会的，不是所有工厂，而是：

- 业务结构多元
- 研产销链条长
- 管理层正在追求经营透明度与标准化复制
- 质量与库存风险高

### 6. 内部内容规划反过来验证了哪些案例最值得当“标杆”

从产品内容节奏和品牌内容规划看，内部非常清楚什么案例最有传播价值：

- 能代表新产品落地
- 能代表 AI+BI 的前沿场景
- 能支撑多种内容形态复用
- 能同时服务市场宣发、售前打单、生态合作与品牌背书

这说明未来潜客名单不应只做“会买吗”，还应该标注：

- `是否有标杆传播潜力`
- `是否适合作为新行业样板间`
- `是否能承载 AI 新产品案例`

## 十一、对潜客分析方法的修正

结合 PDF 与 Markdown 的系统学习，后续潜客分析应从“行业筛选”升级为“四层筛选”：

### 第一层：行业适配

- 是否属于你们已有成熟案例高密度行业

### 第二层：经营复杂度适配

- 是否有多门店、多渠道、多品牌、多SKU、多组织层级

### 第三层：转型阶段适配

- 是否正在经历直营转加盟、单品牌到多品牌、国内到海外、人工经验到数据化管理等关键阶段变化

### 第四层：标杆价值适配

- 是否值得被做成案例、栏目、白皮书、AI产品标杆或样板间

### A. 泛制造新增认知

#### 1. 制造业拓展不是“智慧工厂替代”，而是从商业价值流切入

从 [制造业拓展2026（持续更新中）.md](/Users/clairaipartner/.openclaw/workspace-main/dingtalk_docs/2026-03-28/additional_folder/泛制造/制造业拓展2026（持续更新中）.md) 看，内部已经明确：

- 不能把“智能制造”简单等同于“工厂数字化看板”
- 更适合从 `商业价值流` 切入，而不是只盯产线自动化
- 更强调：
  - 订单-排产-生产-交付全链路可视化
  - 多工厂协同
  - 客户需求协同
  - 计划/订单与制造协同
  - 供应商协同

这说明你们在先进制造的主张，应更偏：

- 经营协同
- 产销协同
- 多组织协同
- 管理驾驶舱

而不是去和 MES/SCADA 正面竞争。

#### 2. 制造业重点客群画像更清晰了

新增案例显示，制造业里更适合你们的不是泛工厂，而是这些类型：

- `多工厂、多产线、多事业部` 的离散制造企业
  - 例：兆驰集团
- `研产销链条长、前中后台系统多、IPO/合规要求高` 的企业
  - 例：衡美健康（CDMO）
- `渠道链条复杂、营销与经营要联动` 的技术型制造企业
  - 例：某医疗器械上市企业

共同特征不是“生产复杂”本身，而是：

- 数据分散
- 组织复杂
- 管理半径大
- 经营协同难
- 财务与业务需要打通

#### 3. 制造业的三条高价值切入线

基于新增案例，先进制造可优先沿这三条线切入：

- `LTC/订单到回款`
  - 适合 CDMO、项目制制造、复杂销售型制造企业
- `多工厂计划达成与生产协同`
  - 适合离散制造、消费电子、装配型企业
- `渠道效率 + 技术品牌`
  - 适合医疗器械、设备类、技术型制造企业

#### 4. 制造业产品与生态短板也被明确写出来了

内部文档直接指出当前前线常遇到的能力 gap：

- 填报审批能力不足
- 管报/财报标准化模板还不够强
- 大屏定制能力需要伙伴协同
- 需要制造业可参观样板间

这对潜客分析有帮助，因为它意味着：

- 先进制造潜客不只看“会不会买”
- 还要看“当前产品能力能否接住”“是否需要伙伴协同”“是否值得经营成样板间”

### B. 跨境电商新增认知

#### 1. 跨境电商已经从尝试性行业，变成明显增长中的重点客群

从 [跨境电商出海吧🚢.md](/Users/clairaipartner/.openclaw/workspace-main/dingtalk_docs/2026-03-28/additional_folder/跨境电商/跨境电商出海吧🚢.md) 看：

- 2025 年跨境电商客群合同额、客户数、客单价、续费金额都有明显提升
- 已经不是“可试可不试”的方向，而是实打实跑出增长的板块
- 华南是当前最强区域阵地

这与用户补充的“跨境电商是 2026 重点拓展对象”高度一致。

#### 2. 跨境电商的核心 JTBD 被内部总结得很清楚

新增材料里，跨境电商的核心痛点基本收敛为四条：

- `目标国家市场洞察 -> 选品`
- `多平台多店铺精细化运营 -> 运营`
- `长链路库存与供需平衡 -> 供应链`
- `T+1利润分析 -> 业财一体化`

这说明后续找潜客时，不应只写“跨境电商企业”，而应继续细分为：

- 重运营型
- 重供应链型
- 重财务利润型
- 重选品市场洞察型

#### 3. 你们在跨境电商里的优势位置也更明确

内部材料已经给出竞争认知：

- 小体量客户未必是最佳 ICP
- 中腰部客户你们更有优势
- 这类客户通常内部有 IT，且愿意自己做底层建设
- 更看重产品能力 + 场景适配，而不是纯重实施

因此更合适的跨境电商潜客画像是：

- 年销售额 5 亿以上
- 多平台 / 多店铺 / 多区域
- 有内部 IT 或数据团队
- 已经意识到利润、库存、运营协同的问题

#### 4. 跨境电商已经具备成体系的 ABM 物料逻辑

从 [跨境电商 - ABM物料.md](/Users/clairaipartner/.openclaw/workspace-main/dingtalk_docs/2026-03-28/additional_folder/跨境电商/跨境电商 - ABM物料.md) 可以看出，内部已经开始把跨境电商打法固化为：

- 敲门砖物料
- 解决方案物料
- 精品应用 Demo
- Top 案例及解读

这说明跨境电商不是“先研究再说”，而是已经具备面向潜客推进的初步作战套件。

### C. 对后续潜客分析的直接修正

结合这轮新增材料，后续潜客分析需要显式新增两类标签：

- `制造业经营协同型`
  - 多工厂、多事业部、订单-排产-生产-交付链路长、适合经营型 BI 切入
- `跨境电商中腰部高复杂度型`
  - 多平台、多店铺、多国家、利润与供应链问题突出、内部具备 IT/数据能力

同时，优先级逻辑应进一步明确为：

1. `零售消费主阵地`
   - 做深做透，持续扩展相邻客群
2. `跨境电商重点拓展`
   - 优先找已具备成熟 JTBD 和 ABM 物料支撑的客户
3. `先进制造重点拓展`
   - 优先找经营复杂度高、协同价值强、可沉淀标杆样板间的客户
